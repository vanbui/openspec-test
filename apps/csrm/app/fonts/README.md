## Coverage

Latin is preloaded. Latin-ext and, for Plus Jakarta Sans and IBM Plex Mono, vietnamese are downloaded only when a page renders one of their characters (`unicode-range`); they are never preloaded.

Each font token lists the latin-ext companion first, then the vietnamese companion, then the latin face. The two subsets share 24 code points (Ă ă Đ đ Ĩ ĩ Ũ ũ Ơ ơ Ư ư, U+0304, U+0308, U+0329, U+1EF2-1EF9 and U+20AB), so latin-ext serves those, and the vietnamese file loads only for the Vietnamese tone letters and combining marks no other subset covers.

Instrument Serif has no vietnamese subset (@fontsource ships only latin and latin-ext), so Vietnamese tone letters in display text fall back to Times New Roman. Cyrillic is not shipped.

## Verify and update

Verify with `sha256sum *.woff2 *.txt` in this directory against the tables; the unit test `src/lib/security/self-hosted-fonts.test.ts` checks every row on every run.

To update: `npm pack <package>@<exact version>` in a scratch directory, check the tarball against the registry's `dist.integrity`, extract it, copy the files unmodified, then update both file tables, the source table, `../fonts.ts` and the tests.
