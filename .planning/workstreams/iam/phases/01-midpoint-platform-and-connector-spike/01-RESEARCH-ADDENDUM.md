# Phase 1 pinned-contract corrections

Checked 2026-10-13 during plan revision; no deployment compatibility result is claimed.

- Docker [compose up](https://docs.docker.com/reference/cli/docker/compose/up/) explicitly documents --force-recreate as recreating unchanged containers. Standard startup now includes it, preserving named volumes while ensuring the completed init is recreated. Consecutive no-down startup tests verify the guarantee during execution.
- Docker [merge rules](https://docs.docker.com/reference/compose-file/merge/) require !override to replace ports rather than append them (Compose>=2.24.4). The isolated override remaps all fixed container names, every named volume including clamav-db, and every host port; inherited internal DNS/health/init/mount settings remain canonical.
- Executed the pinned connector V1.2.9 wrapper's generateConfiguration in an ephemeral gradle:7.2-jdk11 container with BUILD_NUMBER=0. Generated Scim2Configuration has private String token and public String getToken annotated confidential=true, required=true. Resolved source-defined config plugin was 3.0.5-21. This is metadata inspection, not a runtime connector go gate.
