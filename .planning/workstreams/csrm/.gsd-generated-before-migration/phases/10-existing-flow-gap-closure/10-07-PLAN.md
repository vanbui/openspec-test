## Phase Goal

**As a** Security Analyst or Requestor, **I want to** have the existing request, questionnaire, assessment and administration screens work as they say, **so that** today's flow completes without workarounds, lost input or misleading messages.

This plan's slice: every refusal the UAT met now states its real reason in plain words, with a next step where one exists.

<objective>
Turn plan 10-06's reason codes into UI-SPEC §10.2's copy in the Server Actions for requests, questionnaires and questionnaire generation, and replace every "changed, reload" 409 fallback (§10.3). Save failures also report whether autosave may retry. The components already render an action's `formError` inside their dialogs; the governance form and the save status (plans 10-09 and 10-08) consume the extra fields.

Purpose: UX-06 criterion 1 (UAT-036): refusals state their real reason.
Output: one zod-free copy module with its test, three action modules mapping reasons, and their updated tests.

Edits Strapi source? No. Runs Playwright? No.
</objective>

## Recorded planning decisions

- **One copy module.** `apps/csrm/src/lib/api/refusal-copy.ts` holds families `requestRevert` (A), `questionnaireRevert` (B), `questionnaireSubmit` (D), `questionnaireRelease` (E), `returnToReview` (F), `questionChange` (G), `questionDelete` (H) and `questionnaireGeneration` (I), each a partial map from `ConflictReason` to its sentence plus a `fallback`; H reuses G's sentences for the five shared codes (§10.2 H). `answerSaveRefusal(status, reason)` returns `{ message, failure }` for C. `refusalMessage(family, reason)` returns the family's sentence or its fallback.
- **Request 409s outside the D-22 families** (create, update and submit) read `This request can’t be saved in its current state.` (§10.3 names the update form; the submit action also saves the request's fields, so it uses the same sentence).
- **The existing 400, 403, 404 and unavailable messages stay** (§10.3), except the answer-save 403 and 400 (C), which §10.2 rewrites.
- **Results carry `reason`** as an optional field on the failure branch of `RequestActionResult`, `QuestionnaireActionResult`, `QuestionnaireGovernanceActionResult` and `AssessmentServerActionResult`, never the Strapi message.
