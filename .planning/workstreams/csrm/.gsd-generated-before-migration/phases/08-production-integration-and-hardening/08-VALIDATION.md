## Sampling Rate

- **After every task commit:** quick-run the touched Strapi test files and the matching web test files, by path (under 90 s per Strapi file, under 20 s per web file).
- **After every plan:** the full Strapi suite, the full web suite, `typecheck`, `api:check`, and `git status --porcelain` (empty once plan 08-02 has landed). UI plans additionally run their targeted Playwright specs once at the end of the plan, dev servers stopped; plans 08-02, 08-07, 08-09, 08-10, 08-11, 08-12 and 08-14 each end with one full Playwright run because they change something every spec depends on (the harness, shared copy, the shell, the CSP, the projects, the sweep, the gate).
- **Before `$gsd-verify-work`:** the final plan runs the full five-command gate with the production-build E2E in every project, records the run (counts, duration, flaky count, a webServer log excerpt showing `next start`) and the empty `git status`.
- **Max feedback latency:** 90 s at task level; the production-build E2E only at plan level.
