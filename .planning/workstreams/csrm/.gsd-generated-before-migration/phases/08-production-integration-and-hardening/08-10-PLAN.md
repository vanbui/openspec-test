## Recorded planning decisions

- **CSP mechanism (planner's discretion, research §F3.1, Pattern 2):** nonce through `proxy.ts` (the Next 16 proxy convention; `middleware.ts` is deprecated) because every application route is already dynamic (`force-dynamic` in `app/(app)/layout.tsx`), Next applies the nonce it reads from the request's `Content-Security-Policy` header to its own inline scripts, and a static policy would need `'unsafe-inline'` for scripts, which D-19 forbids. SRI was rejected: experimental and unable to cover dynamically generated scripts.
- **`style-src 'self' 'unsafe-inline'` is a recorded residual:** `sonner` injects a `<style>` element at module load (`node_modules/.pnpm/sonner@2.0.8*/node_modules/sonner/dist/index.mjs` lines 5-8) and Radix emits SSR `style` attributes; a nonce in `style-src` would disable `'unsafe-inline'` in CSP3 browsers and block them. Scripts stay strict. If the first sweep shows a `style-src` violation from a different source, name it in the record before widening anything.
- **The policy builder is a plain pure module** (`src/lib/security/content-security-policy.ts`, no `server-only`): it holds no secret and must be unit-testable without mocking; `proxy.ts` is the only production caller.
- **Matcher:** `'/((?!_next/static|_next/image|icon.png).*)'` with `missing: [{ type: 'header', key: 'next-router-prefetch' }, { type: 'header', key: 'purpose', value: 'prefetch' }]` (the CSP guide's recommendation); excluded requests still receive the static headers from `headers()`.
- **Sweep route list** (both actors where the actor can reach the route, refusals included): analyst `/app`, `/app/requests`, `/app/requests/new`, first `/app/requests/{id}`, `/app/questionnaires`, `/app/assessments`, `/app/review`, `/app/review/requests`, first `/app/review/requests/{id}`, `/app/review/questionnaires`, first `/app/review/questionnaires/{id}`, `/app/review/assessments`, first `/app/review/assessments/{id}`, `/app/risks`, first `/app/risks/{id}`, `/app/alerts`, `/app/reports`, the four reports, `/app/admin/{risk-types,controls,information-systems,information-assets}` with `/new` and `/import`; Requestor `/app`, `/app/requests`, `/app/requests/new`, first `/app/requests/{id}`, `/app/questionnaires`, first `/app/questionnaires/{id}`, `/app/assessments`, first `/app/assessments/{id}`, and the refusals `/app/review`, `/app/risks`, `/app/alerts`, `/app/reports`, `/app/admin/controls`; plus `/sign-in` signed out and `/app/this-route-does-not-exist`.
