## Contract change

The questionnaire summary did not declare the timeline, so the events could not be served without
adding `events` and a `QuestionnaireRevisionTimelineEvent` component to
`docs/references/specification.json`. The addition is additive and minimal, and the generated
client was regenerated from the contract rather than hand-edited, which is what `pnpm api:check`
verifies. Plan 01 still owns the phase's published surface; this is the one declaration D-09
needs that it did not carry.

## Defects found and fixed after execution

1. **The projection reported each actor's documentId as their display name.** An opaque
   identifier rendered where a person's name belongs reads as though it were one. The log stores
   only the acting documentId, so the name is genuinely unknown and is now projected as null;
   the timeline says "An analyst". Resolving the name needs a user lookup the projection does
   not perform, and is recorded as a follow-up.
2. **The generated client was hand-edited rather than regenerated,** so `pnpm api:check` failed.
3. **`events` was defaulted to an empty array,** which told every other questionnaire projection
   that a questionnaire had no revisions when the timeline had simply never been asked for. It is
   now absent unless served.
4. **The Requestor's summary was not in date order.** It listed release events, then the
   collapsed question changes, then cleared answers, regardless of when each happened, which a
   dated timeline cannot do. The collapsed change entry now takes the date of the most recent
   change and the whole summary sorts by date.
5. **Three mounted assertions used the wrong fixture values** — a question key from a different
   fixture, and the identity header string where the actor's user document was meant.

## Follow-up recorded

The analyst timeline names an actor only as "An analyst". Resolving each event's documentId to
its display name needs a bounded user lookup in the projection; the release fact already carries
a populated relation and does show the name.
