## Sampling Rate

- **After every task commit:** the task's `<automated>` command (the touched web files by path; `typecheck` when types change; `api:check` after a spec change; the touched Strapi files by path, with dev servers stopped).
- **After every plan:** each Strapi plan ends with the full Strapi suite (04, 05, 06, 07, 08, 09); each web plan ends with the full web suite, typecheck and lint (10, 11, 12, 13, 14); 17.2-15 runs Playwright per spec, then the full gate.
- **Before `/gsd-verify-work`:** the full suite must be green (the phase gate). Counts are recorded against the baseline (web 2,048, Strapi 578 and Playwright 84 at `678b117`, plus every phase executed since).
- **Max feedback latency:** 90 seconds at task level, except the Strapi-suite and Playwright tasks named above.
