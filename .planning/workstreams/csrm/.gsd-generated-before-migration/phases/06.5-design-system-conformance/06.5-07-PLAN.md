<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser query to server fixture resolver | An untrusted query must not turn a presentation harness into an authorization bypass. |
| Playwright process to disposable Next process | The fixture capability is conveyed only through a unique local runtime attestation. |
| Route server component to Strapi typed service | Service outcomes, including 403, are authoritative over test presentation choices. |

</threat_model>
