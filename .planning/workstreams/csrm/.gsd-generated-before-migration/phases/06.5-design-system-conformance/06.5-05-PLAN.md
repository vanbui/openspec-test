## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser query to server-only resolver | A caller-controlled query attempts to select UI fixture behavior. |
| Route page to typed services and Strapi | Route rendering must not replace server authorization or reveal protected records. |
| Test fixture to visible presentation | A marker can otherwise hide an inaccessible, empty, or misleading state. |
