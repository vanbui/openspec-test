## Recorded planning decisions

- **Active forms.** `isActiveRisk(value)` is true for a record whose `withdrawnAt` is `null` or absent and false for any other value (a non-object is false); `activeRisks(list)` filters with it and returns a new array; `ACTIVE_RISK_FILTER = { withdrawnAt: { $null: true } }` and `WITHDRAWN_RISK_FILTER = { withdrawnAt: { $notNull: true } }` (frozen); `activeRiskSql(alias)` returns `` `${alias}.withdrawn_at IS NULL` `` and refuses an alias outside `/^[a-z_][a-z0-9_]{0,30}$/`.
- **Reason text.** `parseReasonText(value)` in `revert-reason.ts` returns the trimmed string when it has 1 to `REVERT_REASON_MAX_LENGTH` characters and null otherwise; `parseRevertReason` calls it and keeps its exact messages and one-key rule.
- **Curation body.** `parseRiskCurationBody(body)` accepts exactly `{ riskIds, reason }` or `{ riskIds, undo: true }`; `riskIds` is an array of 1 to `RISK_CURATION_BATCH_MAX` (200) strings of 1 to 255 characters, all distinct; anything else throws `RiskCurationBodyError` (a 400 at the caller) with a safe message. It returns `{ riskIds, mode: "reason", reason } | { riskIds, mode: "undo" }`.
- **Partition.** `partitionWithdrawal(risks)` takes `{ documentId, withdrawnAt }` rows and returns `{ applied, unchanged }` (withdrawn → unchanged); `partitionReinstatement(risks)` returns `{ applied, unchanged }` (active → unchanged) or `{ refusal: "RISK_NOT_WITHDRAWN" }` when every row is active. Order follows the request's `riskIds`.
- **History changes.** `riskChanges(before, after, fields)` compares each named field after normalisation (string trimmed, empty string as null; a relation compared by `documentId`, recorded as `{ documentId, label }` with the caller's label); dates as `YYYY-MM-DD` strings; returns `[{ field, from, to }]` in `fields` order. `controlImplementationChanges(before, after)` does the same over the control implementation's writable fields, with `before` null for an addition and `after` null for a removal (the removal keeps every value). `buildRiskHistoryChanges({ fields, control? })` returns the envelope `{ schemaVersion: 1, fields, control? }` and throws on more than 40 fields; `parseRiskHistoryChanges(value)` returns the frozen envelope or null, never throwing. `RISK_HISTORY_KINDS` and `RISK_HISTORY_SOURCES` are frozen arrays of the approved values.
- **Item core generalisation.** In `proposal-items.ts`, `DecisionPayloadParsers` gains `itemKey(value: string): boolean` and an optional `edits` field-name list; when absent, the questionnaire rules (`i-1` to `i-30`; the six questionnaire edit fields) apply unchanged. `DecisionCause` gains `{ kind: "risk-withdrawn", riskDocumentId }` and `{ kind: "assessment-not-editable" }`. The fold and `nextState` do not change.
- **Risk envelope.** `parseRiskProposal(value, allowed?)` validates the approved v1 exactly: operation, outcome, suggestion items `s-1` to `s-8` (each `proposed` parsed by Phase 12's internal draft risk parser for one risk), unit items `u-{unit}` with `fields` equal to that unit's definition, `base` and `proposed` holding exactly those fields, optional `sources` (Phase 12 citation shape), `uncited` (Phase 12 shape) and `aiAccept` (boolean), at most 60 adjustments with codes from `RISK_PROPOSAL_ADJUSTMENT_CODES`; null on anything else. `riskDecisionPayloads` supplies `itemKey`, `before` (`{ riskDocumentId, values, fieldFacts }`, where `fieldFacts` maps each unit field to its Phase 12 per-field fact before the accept or null, parsed with 12-04's field-fact parser) and `applied` (`{ riskDocumentId, values? }`); `parseRiskDecisionEvents(value)` returns the parsed events or null.
- **Units.** `RISK_UNIT_DEFINITIONS` maps each approved unit key to its fields and focus part (`statement`: risk type, issue and risk statements, category, sub-category, cause, impact, information system, information asset with classification; `ratings`: inherent and residual rating units and their rationales; `treatment`: treatment action and plan). `normaliseRiskValues(risk, fields)` uses the history normalisation. `diffIntoUnits(base, proposed, { focus })` returns `{ units, adjustments }`: unchanged units are dropped as `no-change`, units outside the focus as `outside-focus`; a proposed treatment action of `Accept` that differs from the base forms the `treatment` unit with the plan, otherwise `treatment-action` and `treatment-plan` are separate. `isUnitStale(unit, current)` compares every unit field with its base after normalisation. `unitApplyValues(unit)` returns the proposed values; restore uses the event's `before`.
- **Accept rule.** `aiAcceptCheck({ residualRating, plan, hasPlannedControl })` returns null, `"accept-not-permitted"` (when `acceptProposalAllowed(residualRating)` is false or the plan is blank) or `"accept-with-planned-control"`. `residualRatingAfter(current, units)` derives the residual rating from the current values with the units' proposed values applied in order, through `deriveRating`. Phase 12's `riskHasPlannedControl` stays the predicate; callers pass its boolean in (no second predicate).
- **Duplicates.** `riskComparisonText(risk)` is the risk statement and cause joined by a space; `classifyProposedRisk(candidate, pools)` takes pools `active`, `withdrawn`, `rejected`, `open` and `sameRun`, returns the first near-identical match in that order (`{ tier: "near-identical", against: { kind, ref } }`), else the highest-scoring similar match at `RISK_SIMILARITY_THRESHOLD` (0.5) or above (`{ tier: "similar", against, score }`), else `{ tier: "distinct" }`.
