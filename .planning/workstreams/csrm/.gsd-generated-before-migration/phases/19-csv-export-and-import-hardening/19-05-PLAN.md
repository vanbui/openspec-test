## Phase Goal

**As a** Security Analyst or risk manager, **I want to** export any list I can see and to import spreadsheets without fighting the format, **so that** CSRM fits the Excel work around it.

This plan's slice: the first export served end to end in the API. Bob's filtered Risk register comes back as a workbook or a CSV with a formula-like value as text, through one grant, the register read, the human-only and service-identity refusals, the cap and one log line, at the URL the catalogue reserved.
