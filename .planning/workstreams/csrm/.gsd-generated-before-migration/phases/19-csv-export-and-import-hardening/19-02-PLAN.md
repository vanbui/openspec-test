## Phase Goal

**As a** Security Analyst or risk manager, **I want to** export any list I can see and to import spreadsheets without fighting the format, **so that** CSRM fits the Excel work around it.

This plan's slice: every refusal an export or an import can meet is one closed code that Strapi sends, the contract publishes, the transport keeps with its safe details, and the web words with its fix.
