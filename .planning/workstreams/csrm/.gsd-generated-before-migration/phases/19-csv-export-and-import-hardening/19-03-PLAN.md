## Recorded planning decisions

- **Neutraliser (`neutralise.ts`).** `NEUTRALISER_MARK = "'"`. `needsNeutraliser(value)` is true exactly when the value matches `/^'*(?:[=+\-@\t\r\n＝＋－＠]|\s+[=+\-@＝＋－＠])/u`: today's trigger pattern from `csv-import.ts`, or one or more single quotes followed by a trigger (19-RESEARCH Pitfall 9). `sanitizeSpreadsheetCell(value)` returns `'` + value when `needsNeutraliser`, else value. `stripNeutraliserMark(value)` removes exactly one leading `'` only when the remainder matches the same pattern (a trigger, or quotes then a trigger), else returns value unchanged.
- **CSV writer (`csv-writer.ts`).** `UTF8_BOM` (EF BB BF). `writeCsv({ header: readonly string[]; rows: readonly (readonly CsvCell[])[] }): Buffer` where `CsvCell = null | { kind: "text"; value: string } | { kind: "number"; value: number } | { kind: "date"; isoDate: string }`; header labels and text cells are quoted with `"` doubled; text cells pass through `sanitizeSpreadsheetCell`; null is an empty field; lines joined by CRLF with a final CRLF.
- **XLSX writer (`xlsx-writer.ts`, the only importer of `write-excel-file`).** `XLSX_SHEET_NAME_MAX = 31`; `safeSheetName(name)` removes `\ / ? * [ ] :` and cuts to 31 characters; `writeWorkbook(sheets: readonly WorkbookSheet[]): Promise<Buffer>` with `WorkbookSheet = { name; header: readonly string[]; rows: readonly (readonly SheetCell[])[]; widths: readonly number[] }` and `SheetCell = null | { kind: "text"; value: string } | { kind: "number"; value: number } | { kind: "date"; value: Date }` (the UTC midnight of a calendar date, 19-RESEARCH Pitfall 5). Header cells bold; `stickyRowsCount: 1`; text cells `type: String`, `format: "@"`, neutralised; numbers `type: Number`; dates `type: Date`, `format: "d mmm yyyy"`; never `type: "Formula"`. Import through `write-excel-file/node`; if `tsc` cannot resolve that subpath under the backend's node10 resolution, import the entry whose declaration resolves and record which in the summary (19-RESEARCH Pitfall 3).
- **First-sheet read (`xlsx-reader.ts`).** Add `readFirstSheet(bytes: Buffer): Promise<ReadonlyArray<ReadonlyArray<string | number | boolean | Date | null>>>` calling `read-excel-file/universal`'s sheet read for sheet 1 with `trim: false` on an exactly sliced `ArrayBuffer` (19-RESEARCH Pitfall 4); map `InvalidInputError.code` `XLS_FILE_NOT_SUPPORTED` → `IMPORT_LEGACY_XLS`, `FILE_NOT_SUPPORTED` and `INVALID_ZIP` → `IMPORT_FILE_TYPE`, through `XlsxReadError` carrying the reason. Keep 14-02's exports unchanged.
- **Import reader (`import-file.ts`).** `readImportFile({ bytes, fileName, mimeType }): Promise<{ format: "csv" | "xlsx"; header: readonly string[]; rows: readonly ImportRow[] }>` where `ImportRow = { rowNumber: number; cells: readonly (string | number | boolean | null)[]; byteLength: number }`, or throws `ImportFileRefusal` (`reason: ConflictReason`, `status`, `found?`). Order: extension allow-list `.csv`, `.xlsx` (else `IMPORT_FILE_TYPE`, 415; the MIME type is advisory only: allowed are empty, `application/octet-stream`, `text/csv`, `application/vnd.ms-excel` for `.csv` and the OOXML type for `.xlsx`); size at most `CSV_MAX_BYTES` 5,242,880 (else `IMPORT_FILE_TOO_LARGE`, 413, `found.bytes`); the signature decides the path, never the extension: `PK\x03\x04` → XLSX; `D0 CF 11 E0 A1 B1 1A E1` → `IMPORT_ENCRYPTED_WORKBOOK` when the CFB bytes contain the UTF-16LE name `EncryptedPackage`, else `IMPORT_LEGACY_XLS`; `FF FE`, `FE FF`, or a NUL byte in the first 4 KiB → `IMPORT_ENCODING_UTF16`; otherwise CSV text. A `.csv` name with XLSX bytes or the reverse is `IMPORT_FILE_TYPE`.
  - CSV: strict UTF-8 with the BOM stripped; on failure `IMPORT_ENCODING_UNKNOWN` when any byte is 0x81, 0x8D, 0x8F, 0x90 or 0x9D (undefined in Windows-1252), else `IMPORT_ENCODING_WINDOWS_1252`; CSRM never decodes a legacy encoding. Delimiter: refuse `IMPORT_DELIMITER` (`found.delimiter` `semicolon` or `tab`) only when the header line has no comma and has `;` or a tab. Parse with today's `csv-parse` options (`bom: true`, `relax_column_count: false`, `relax_quotes: false`, `trim: false`), `max_record_size` raised to the 5 MiB file bound so one long row never aborts the file.
  - XLSX: `readZipDirectory(bytes, { maxEntries: 512, maxDeclaredTotal: 52_428_800, maxRatio: 200 })`; `ZIP_ENCRYPTED` → `IMPORT_ENCRYPTED_WORKBOOK`; an entry named `xl/vbaProject.bin` or a `[Content_Types].xml` naming `macroEnabled` → `IMPORT_MACRO_WORKBOOK`; `ZIP_TOO_MANY_ENTRIES`, `ZIP_TOO_LARGE`, `ZIP_RATIO`, `ZIP64_UNSUPPORTED` and `ZIP_INFLATE_LIMIT` → `IMPORT_WORKBOOK_TOO_LARGE`; `ZIP_MALFORMED` and `ZIP_METHOD_UNSUPPORTED` → `IMPORT_FILE_TYPE`. Then inflate every entry with `readZipEntry(…, { maxOutputLength: remaining })` against the 50 MiB budget before `readFirstSheet` runs.
  - Both: the first row is the header (`IMPORT_NO_HEADER` when it is empty or every cell is blank); trailing fully blank rows are dropped; no data row → `IMPORT_NO_ROWS`; more than 5,000 data rows → `IMPORT_TOO_MANY_ROWS` (`found.rows`). A row whose UTF-8 length exceeds 65,536 bytes is returned with `byteLength` so the classifier rejects that row with `VALUE_TOO_LONG` (field null); the file is not refused for it.
- **Header matching (`header-match.ts`).** `headerKey(value) = value.trim().normalize("NFKC").toLocaleLowerCase("en-AU").replace(/[\s_-]+/gu, "")`. `matchHeaders(headers, columns, { knownIgnored })` where a column is `{ field; label; required: boolean; aliases?: readonly string[] }` and `knownIgnored` is `{ issuesHeader: "Issues"; readOnlyLabels: readonly string[] }`; returns `{ mapping: readonly (string | null)[]; warnings: readonly string[]; notes: readonly ("issues-column" | "read-only-columns")[] }` or throws `ImportFileRefusal` with `IMPORT_DUPLICATE_HEADER` (`found.headers` both as typed, `found.labels` the column's label) or `IMPORT_MISSING_COLUMN` (`found.labels` every missing required label). Warnings list unknown headers as typed, in file order. No aliases are proposed in this phase (D-27: none required).
- **Value conversion (`value-convert.ts`).** `CLEAR_TOKEN = "#CLEAR"`. `convertCell(raw, column, { mode: "create" | "update" })` where `column` is `{ field; label; kind: "text" | "flag" | "enum"; required; maxLength; values? }`, returning `{ kind: "value"; value: string | boolean } | { kind: "blank" } | { kind: "clear" } | { kind: "issue"; code; message }`. Trim once; number cells become `String(value)`; boolean cells are flags; text then passes `stripNeutraliserMark`; `#CLEAR` (any case, whole cell) is `clear` on an optional field in update mode, `blank` in create mode, and an issue `CLEAR_REQUIRED` with message `{label} is required, so #CLEAR can’t empty it.` on a required field; flags accept `yes`, `no`, `y`, `n`, `true`, `false` after lower-casing, else `INVALID_BOOLEAN` with `{label} must be Yes or No. Y, N, TRUE and FALSE also work.`; enumerations match case-insensitively and return the canonical value, else today's `INVALID_ENUM`; length over `maxLength` is today's `VALUE_TOO_LONG`. `VALUE_CONVERTERS` is a frozen map from `kind` to converter, the interface Phase 18 extends with dates, scale labels, people and controls (D-29).
