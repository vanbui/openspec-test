## Phase Goal

**As a** Security Analyst or risk manager, **I want to** export any list I can see and to import spreadsheets without fighting the format, **so that** CSRM fits the Excel work around it.

This plan's slice: the request lists export. Bob exports his review queue as it stands, with its assignee column and filters; anyone exports their own requests and never someone else's.
