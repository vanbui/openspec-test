## Phase Goal

**As a** Security Analyst, **I want** an assessment's risks in a table I can edit, copy and paste like Excel or a SharePoint list, **so that** reviewing and updating many risks takes minutes rather than a long scroll.

This plan's slice: Excel both ways. Rows copied out paste into Excel as rows and columns; a range copied from Excel or SharePoint pastes in through a preview that converts what people type and applies nothing until the analyst chooses; and two analysts on one risk see a conflict.

## Recorded planning decisions

- **Neutraliser copy.** `apps/csrm/src/lib/spreadsheets/neutralise.ts` is a byte-identical copy of `apps/backend/src/csrm/spreadsheets/neutralise.ts`; `neutralise.test.ts` reads both files and asserts equal bytes, plus `sanitizeSpreadsheetCell("=1+1")` and `stripNeutraliserMark` round trips. If 19-03's file imports another module, copy that module beside it the same way and record it.
- **Clipboard (`risk-table-clipboard.ts`, zod-free).** `excelSerial("2026-11-30")` = `(Date.UTC(y, m - 1, d) - Date.UTC(1899, 11, 30)) / 86_400_000` (46356). `writeClipboardRange({ rows, columns, includeHeader })` returns `{ text, html }`: text is tab-separated with Excel quoting (fields containing a tab, line break or quote are quoted, quotes doubled), CRLF row ends; dates `dd/mm/yyyy`; every text value passes `sanitizeSpreadsheetCell`; html is `<html xmlns:x="urn:schemas-microsoft-com:office:excel"><body><table>` with `<th>` headers when included, date cells `<td x:num="{serial}" style="mso-number-format:'dd\/mm\/yyyy'">30/11/2026</td>`, text cells `style="mso-number-format:'\@'"` with escaped, neutralised text. `readClipboardTable({ text, html })` reads `text/plain` first (Excel's TSV with quotes), else `text/html` through `new DOMParser().parseFromString(html, "text/html")`, reading only `textContent` of `tr`/`td`/`th`; returns `string[][]` or null (X2 `The clipboard holds no cells to paste.`). `mapPaste({ table, activeCell, columns, rows })` returns placements `{ target: { rowId | newIndex, columnKey }, raw }`, skipped read-only cells, unknown risk numbers and the mode (`headers` when the first row's `headerKey`s match visible column headers, `riskNumber` when a `Risk number` column is among them, else `position`).
- **Converter mirror (`risk-value-convert.ts`, zod-free).** The paste kinds of 18-02 with the same rules and messages (`DATE_INVALID`, `SCALE_VALUE_INVALID`, `PERSON_NOT_FOUND`, `PERSON_AMBIGUOUS`, `RECORD_NOT_FOUND`, `CONTROL_NOT_FOUND`), stripping the neutraliser mark first; lookups are async functions supplied by the table. `risk-value-convert.test.ts` reads the backend fixture by relative path and asserts every `conversions` case with the fixture's lookup tables.
- **Lookups.** People: `searchActiveUsersAction` once per distinct name (≥ 2 characters), exact display-name equality among results (one: match; several: many; none: none); the search is logged by Strapi (G-17). Records and controls: `resolvePasteValuesAction({ kind: "riskType" | "system" | "asset" | "control", values })` in `risk-table-actions.ts`, calling the existing typed reads (`listRiskTypes`, the system and asset searches, 10's control search) and matching names or numbers exactly.
- **Preview (X-55).** `PastePreviewDialog` (`next/dynamic`), complex size (800px): title `Paste {r} rows by {c} columns`; the mapping line (`Matched by column headers.`, `Placed from {risk number} · {column}, by position.` or `Matched rows by risk number.`, then `{s} read-only {cell is|cells are} skipped: {headers}.` and `{x} new {risk|risks} will be added for the rows past the end.`); the summary `{c} {change|changes} to {r} {risk|risks}` · `{e} {cell needs|cells need} attention` (`aria-live="polite"`); `Show` (`All ({c})`, `Needs attention ({e})`); X-24's comparison table (`Cell`, `Current`, `New`, row headers), `Pasted as “{raw}”` captions, error rows with `CircleAlert` and the X2 reason, a `Reason for the override` field in a rating row that differs from the derived one (an error until 1 to 500 characters); `Matching names…` with a skeleton row per pending name after 300ms; actions per amendment 3. Escape and `Cancel paste` apply nothing; applying is one undo step and puts focus on the first changed cell. Before showing, `exceedsRequestLimit` and the 1,000-risk cap refuse with X2's copy (`Save your changes first, then paste the rest.` for the byte bound).
- **Table wiring.** `copy`, `cut` and `paste` events on the grid (Ctrl+C, Ctrl+X, Ctrl+V) and the cell menu's `Copy`, `Cut`, `Paste` (`Paste (press Ctrl+V)` without clipboard permission); a single pasted value over a selection fills every selected editable cell of that column (D-16); paste is not offered below 768px; announcements `Copied {r} rows by {c} columns.` and `Cut {k} cells.`.
- **Playwright helper (`e2e/helpers/clipboard.ts`).** `pasteExcelRange(page, { text, html })` dispatches a `paste` event with a constructed `DataTransfer`; `readCopiedFlavours(page)` reads `navigator.clipboard.read()` after `context.grantPermissions(['clipboard-read', 'clipboard-write'])`.
