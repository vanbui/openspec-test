## Recorded planning decisions

- **Operations** (`CSRM_SHARED_VIEW_GOVERNANCE_OPERATIONS` in `operations.ts`): `listSharedViews`, `renameSharedView`, `unshareSharedView`, `restoreSharedViewSharing`, `transferSharedView` (22-01 URLs), router `routes/shared-view-governance.ts`, `requireAdminScope`; operationIds under tag `configuration`.
- **List.** Every view with `visibility: "analysts"` across view keys, as `SharedViewGovernanceItem` (22-01); `ownerNeedsReplacing` when the owner is inactive or holds no human Security Analyst role; `sharedAt` = the newest `shared` or `sharing-restored` change row's `createdAt` for the view, null when none (shared before Phase 22); query `ownerNeedsReplacing=true` and `page`, `pageSize`; ordered by view key, then owner, then name.
- **Acts.** Rename `{ name, expectedUpdatedAt }` (1–80 after trim; the new owner-and-key uniqueness as 18, `SAVED_VIEW_NAME_TAKEN`); unshare `{ expectedUpdatedAt }` sets `personal`; restore sharing `{ undoOf }` sets `analysts` only when the view's newest change row is `undoOf`, by this Admin, action `unshared`, and the view is still `personal` (else 409 `SHARED_VIEW_CHANGED`); transfer `{ ownerId, expectedUpdatedAt }` to `isEligibleViewOwner(user)` (active, `isEligiblePerson`, holds the human Security Analyst role; else 409 `VIEW_OWNER_NOT_ELIGIBLE`), honouring the new owner's uniqueness and 50-view limit, or `{ ownerId, undoOf }` back to the previous owner without the eligibility check when `undoOf` is this Admin's newest `transferred` row on the view. A stale `expectedUpdatedAt`, or a view no longer shared, is 409 `SHARED_VIEW_CHANGED`; a missing view 404. Each act locks the view row, writes the change row (area `shared-views`, subject `shared-view` with its name; actions `renamed`, `unshared`, `sharing-restored`, `transferred`; fields `name`, `visibility`, `owner` display names) and answers `{ data: SharedViewGovernanceItem, meta: { changeId } }`, the change row's id the web's Undo sends as `undoOf`.
- **Owner's rows.** In `saved-views.ts`, a create with `analysts`, and an update changing `visibility`, write `shared` or `unshared` rows with the owner as actor; deleting a shared view writes `deleted`. `savedViewSharePolicy` is unchanged (18 D-09 stands).
