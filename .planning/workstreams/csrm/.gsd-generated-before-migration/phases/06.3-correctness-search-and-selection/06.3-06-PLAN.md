Purpose: UX-02 requires server-enforced authorization, query caps, and bounded DTO projections; an OpenAPI declaration alone cannot supply them.
Output: Mounted selector routes, controller/service query builders, policy decisions, contract/catalogue synchronization, generated declarations, and two-actor server tests.
</objective>

## Trust Boundaries

| Boundary | Description |
|---|---|
| browser selector input to Strapi policy | Search strings, pages, page sizes, and selected identifiers are untrusted and cannot grant inventory visibility. |
| selector projection to Request form | The client may render only bounded server-selected label data and must persist relation identifiers. |
