## Phase Goal

**As a** risk manager or leader, **I want** trends, ageing, cycle times and a heat map, **so that** I can see whether risk and the assessment process are improving.

## Recorded planning decisions

- **Exposure (`riskExposure`).** `heatMap` = `riskHeatMap(strapi, { stage: "released", state: "open", ...filters })` plus `underAssessment` = the register's total for `{ stage: "under-assessment", state: "open", ...filters }`; `exposedInformationAssets` = the exposed-systems query's twin over the risk's Information Asset (top `EXPOSED_SYSTEMS_LIMIT` by High and Critical residual); `riskTypes` = `{ rows: { riskTypeDocumentId, name, critical, high, all }[] (top REPORT_TOP_N by all, then critical, then high, then name), total }`; `acceptedReviews` = `{ accepted: { overdue, dueSoon, notConfirmed, reviewerMissing }, exceptions: { … } }`, each the register's total for `{ stage: "released", state: "open", treatmentAction: "Accept", decisionReview, exception? }`.
- **Treatment (`treatmentPerformance`).** `dueByTreatmentOwner` = `{ rows: { treatmentOwner: { documentId, displayName }, overdue, dueSoon, total }[] (most overdue first, top REPORT_TOP_N), total }` over tracked treatments on released risks through `treatment-due-state.ts`'s predicate (no `targetDate` logic here, G-16).
- **Throughput.** `assessmentThroughput` adds `p90DaysToRelease`, `timeToReleaseSample { sampleSize, truncated, submissionFallbackCount }` from the same `timeToReleaseSample` and `stageStatistics`.
- **Controls.** `controlEffectiveness` counts released open risks by default and adds `underAssessment { implementationStatus }` over open risks not yet released.
- **Spec.** The four report schemas gain those properties (closed); no parameter changes.
- **Export.** Tables `Risk matrix (inherent)`, `Risk matrix (residual)`, `Most exposed Information Assets`, `Risk Types`, `Accepted risks and exceptions`, `Overdue and due soon by treatment owner`, `Under assessment` (controls); vocabulary copied to the web.
- **Web.** Parsers closed; presentation copy, captions, links (UI-SPEC §4.4, §10: cells `/app/risks?state=open&stage=released&{side}Likelihood=&{side}Consequence=` plus filters; under assessment `/app/risks?stage=under-assessment&state=open&display=heat-map`; assets `asset`; Risk Types `riskType` with `residualRating`; accepted `treatmentAction=Accept&decisionReview=` with `exception=yes` for exceptions; owners `treatmentOwner` with `dueState`; controls' row headers plus `stage=under-assessment`); the four views render the sections in §4.4's order; `Total` columns stay plain.
