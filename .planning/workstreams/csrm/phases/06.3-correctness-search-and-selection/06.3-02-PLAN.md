<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| browser query to Strapi builders | Query strings are untrusted and must not select fields, widen scope, or cause unbounded work. |
| Strapi projection to typed client | An incomplete relation or raw document can create data disclosure and response-parser drift. |
| route declaration to generated transport | Contract drift can cause a completed server operation to render as a client failure. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-063-04 | Tampering | list query parameters | high | mitigate | Closed parsers, capped input, allowed status/sort sets, and count/data shared filters. |
| T-063-05 | Information Disclosure | collection projections | high | mitigate | Strapi applies owner/all scope first and returns explicit bounded populated DTOs only. |
| T-063-06 | Denial of Service | search and pagination | medium | mitigate | Maximum text length, page size, sort fields, and explicit count/page queries. |
| T-063-07 | Tampering | route contract | medium | mitigate | Catalogue-byte, served-route, OpenAPI, generation, and declaration assertions run together. |
| T-063-SC | Tampering | dependencies | low | accept | No package installation is planned. |
</threat_model>
