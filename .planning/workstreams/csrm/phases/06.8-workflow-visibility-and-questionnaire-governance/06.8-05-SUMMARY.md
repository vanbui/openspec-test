## Defects found and fixed after execution

1. **The web parser rejected every question governance creates.** Plan 04 introduced the
   version-2 question envelope on the server; the client still accepted only version 1, so the
   first question added through this panel made the whole analyst review screen render its error
   state. Neither suite caught it, because no fixture carried a version-2 question — only driving
   the real panel in a browser did. The client now parses the two versions as a discriminated
   union, so version 1 keeps rejecting a deletion marker it can never legitimately carry, and a
   deleted question is excluded from the active definition, its progress and its submission
   (D-07). A regression test covers both versions and the rejection of an unknown one.
2. **The governance mutations returned a field the contract does not declare.** Plan 04's result
   carried `questions`, which `QuestionnaireGovernanceResult` does not define and which its
   `additionalProperties: false` forbids; the parity guard failed on all four operations. The
   revised question set is read back through the questions route, which already owns the analyst
   projection and its answer masking, so the server no longer duplicates it on the wire.
3. **The question editor could only create Text questions.** The service and action layers
   already accepted every supported answer type and its choices, but the form offered no
   control, so an Analyst could not add a select question at all. The form now offers the six
   supported answer types, reveals a choices field for the two select types, and refuses to save
   a select question with no choices. File upload stays absent: no authorised upload, storage,
   scanning or retention contract exists, so a question the Requestor could never answer must
   not be creatable.
4. **A released but unanswered questionnaire offered no way back.** The governance panel was
   rendered only in the analyst-review and submitted states, so between release and the
   Requestor's submission an Analyst had no route to return it to review and correct it, which
   is the only route D-15 allows.

An existing test asserted that version 2 was an unknown schema version. It now uses version 3,
because version 2 is the envelope this phase introduced.
