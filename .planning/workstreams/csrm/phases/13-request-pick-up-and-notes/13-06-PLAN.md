## Phase Goal

**As a** Security Analyst, **I want to** pick up a request and exchange notes with the Requestor on it, **so that** ownership is clear and new information has a home at any point.

This plan's slice: a Security Analyst can mark any note as changing the AI inputs and undo it, every request says how many notes it holds and how many are new to the reader, no request with notes can be deleted, and only a request's own requestor can submit it.
