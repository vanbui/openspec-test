## Recorded planning decisions

- **Names fixed here** (Planner's Discretion within D-01): `api::csrm-request-note.csrm-request-note` (collection `csrm_request_notes`, `draftAndPublish: false`) with `body` (text), `authorPart` (enumeration `requestor`, `security-analyst`), `sequence` (integer), `postedAt` (datetime), `changesAiInputs` (boolean, default false), `aiInputLog` (json), relations `assessmentRequest` and `author` (manyToOne, no inverse); `api::csrm-request-note.csrm-request-note-read-state` (collection `csrm_request_note_read_states`, `draftAndPublish: false`) with `lastReadAt` (datetime), `lastReadSequence` (integer), relations `reader` and `assessmentRequest` (manyToOne, no inverse). Both types live in one API folder, `apps/backend/src/api/csrm-request-note/`, with no core router.
- **Link tables** (13-RESEARCH §A): `csrm_request_notes_assessment_request_lnk`, `csrm_request_notes_author_lnk`, `csrm_request_note_read_states_reader_lnk`, `csrm_request_note_read_states_assessment_request_lnk`.
- **Bounds** (13-RESEARCH §B): body 1 to 5,000 characters after trimming, CRLF and CR normalised to LF, no C0 control character other than tab and newline; 500 notes per request (`NOTES_LIMIT_REACHED`, 409); 50 marked notes in one AI context (over → `CONTEXT_TOO_LARGE` naming the marked notes); 200 AI-input log events per note (`HISTORY_UNAVAILABLE` at the cap); list pages of at most 50 notes by `before` sequence.
- **Context summary v2 notes section**: `notes: { included: [{ documentId, part, sequence, postedAt, characters }], marked, bound }`. `postedAt` is kept so the "What the AI used" sheet shows the note's time without its text (G-3); a v1 summary reads as "included none".
- **Operations**: `GET` and `POST /api/v1/assessment_requests/{requestId}/notes`, `POST /api/v1/assessment_requests/{requestId}/notes/read`, `PUT /api/v1/assessment_requests/{requestId}/notes/{noteId}/ai_input`; Functions `function.risk_assessment_requests.notes_api` (Requestor and Security Analyst) and `function.risk_assessment_requests.note_ai_input_api` (Security Analyst only); reasons `NOTES_CLOSED`, `NOTES_LIMIT_REACHED`, `REQUEST_HAS_NOTES` (409).
