## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| Plan → schema | A content-type change reaches every later phase's data, so the request assignment attributes and the two notes content types run only after their dated governance approval (G-6) | Content-type schemas |

| Requestor birthright → notes grant | Every identity, the service agent included, holds the Requestor grant, so the reader rule, not the grant, decides who uses a request's notes | Notes, read state |
| Web server and browser → AI-input mark | A caller chooses which free text reaches the AI provider | Note id, mark value |

| Browser → Server Action | The page sends the action and the assignee it showed; Strapi decides | Request id, analyst id, `expectedAnalyst`, reason, note text |
| Browser session storage | Unsent reasons and note text persist in the tab's session, keyed by a hashed owner key and the request | Unsent reason and note text |
| Strapi → browser | Untrusted note text and people names from either actor are rendered to the other | Note bodies, display names, assignment reasons |
| Web server → review queue | Filter values arrive from the query string; the viewer comes from the policy | Closed `assignee` and `notes` filters, page size, queue items |
| Navigation → queue reads | Sidebar counts read the queue with the viewer's own scope | One-row count reads |
| Analyst → dashboard summary | Per-viewer counts computed for the viewer the policy resolved | Dashboard figures |
| Requestor → owner-scoped lists | My requests and its status summary count only the caller's own requests | Unread counts, assignee display name |
| Note text (either actor) → AI provider prompt | Untrusted free text from marked notes crosses into a model prompt inside the escaped requestor data block | Marked note part, sequence and body |
| AI run record → later readers | Run summaries persist and are read by analysts and later phases | v2 context summary (note ids, parts, sequences, times, character counts) |
| Analyst reads → note metadata | The AI-inputs signal names notes by part, sequence and time | Signal (note identity and change kind) |
| Strapi → analyst pages | Note metadata and people names render on analyst record pages and the run sheet | Signal, run-sheet note rows |
| Phase output → development database | The schema sync and seed reach the operator's database on restart | Columns, link tables, the Sam Analyst seed |
