## Phase Goal

**As a** Security Analyst, **I want to** withdraw wrong risks and ask the AI to rewrite one risk or propose missing ones, **so that** the draft ends up complete and correct without rebuilding it by hand.

This plan's slice: the web's typed half of every Phase 16 operation, so the components in 16-12 to 16-15 only render and send intents: services, Server Actions, the zod-free domain rules and copy, and refusal family R.

<objective>
Build `apps/csrm/src/features/risk-curation/`'s schema, service, actions and zod-free domain module for withdrawal, reinstatement, Undo, history, both AI operations, jobs, the proposals read and decisions (D-02, D-11, D-39), with every user-facing rule and string the UI-SPEC fixes (D-15, D-47, D-49), refusal family R (UI-SPEC §13), the new session-draft kinds for no lost input (D-47), the parity and parser-free registrations, and the served inventory's web callers.

Purpose: one typed path from the interface to Strapi (AGENTS), and one tested place for the interface's logic, so no business logic lives in JSX.
Output: seven new web modules and tests, refusal family R, two registrations, the session-draft kinds, the regenerated served inventory.

Edits Strapi source? No. Changes the specification? No. Runs Playwright? No.
</objective>
