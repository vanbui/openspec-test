<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| feature service -> Strapi transport | Typed requests leave the web server for the authoritative production API. |
| environment -> server transport | Base URL configuration must not expose credentials to browser bundles or errors. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-01-01 | Elevation | typed service | mitigate | Services never send development role selectors as Strapi authorization; Strapi is authoritative. |
| T-01-02 | Elevation | record requests | mitigate | Do not model client-side IDOR authorization; depend on the Strapi HTTP harness and document record enforcement gap/contract. |
| T-01-03 | Spoofing | auth contract gap | mitigate | Document Keycloak callback/returnTo contract gap; no redirect proxy or unvalidated callback is added. |
| T-01-04 | Information disclosure | transport/errors/env | mitigate | `server-only` client, no `NEXT_PUBLIC_*` secrets, normalized redacted errors, and ignored local env files. |
| T-01-05 | Information disclosure/CSRF | Strapi calls | mitigate | Preserve backend CORS/session controls; transport does not add browser credential workarounds. |
| T-01-SC | Tampering | OpenAPI/tool dependencies | mitigate | Human legitimacy gate in Plan 01-01 precedes installation; deterministic generation and drift checks detect schema tampering. |
</threat_model>
