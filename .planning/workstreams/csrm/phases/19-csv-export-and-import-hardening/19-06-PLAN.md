## Phase Goal

**As a** Security Analyst or risk manager, **I want to** export any list I can see and to import spreadsheets without fighting the format, **so that** CSRM fits the Excel work around it.

This plan's slice: the first export a person can use. From the Risk register's header, Bob opens the export dialog, chooses a format and columns, and saves the file the server built, with the server's name and count; the dialog, its column choice and the action pattern are the ones every other list reuses.

Prove the dialog's states in Vitest and ROADMAP criterion 1 in Playwright at both widths, with the Requestor's gated page as the UI negative case (D-16, D-38, D-39).
