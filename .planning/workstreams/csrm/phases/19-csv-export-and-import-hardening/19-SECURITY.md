# Phase 19 — Security

> Per-phase security contract: threat register, accepted risks, and audit trail.

## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| Analyst, Requestor and service agent → Strapi export routes | Untrusted until Role → Function → FunctionAPI passes (five API-only export Functions; the four reference-list exports in the Administration Functions), `SERVICE_IDENTITY_REFUSED_OPERATIONS` refuses automation whatever it holds, `HUMAN_ANALYST_ONLY_OPERATIONS` refuses the analyst exports to anyone but the human Security Analyst role, and the export's list read (`underlyingRead`, and for the released assessment its three reads) is held through the same grant path. Navigation and hidden controls are courtesy only. | 14 export operations, assessment ids, report keys |
| Query string or report body → export controls and the list's parser | Closed: `format` is `csv` or `xlsx`, `columns` 1 to 40 unique keys of the view, `timeZone` an IANA zone of at most 64 characters, then the list's own parser; the report body has four keys and its query goes to the report's own parser. | Filters, search, sort, columns, zone, table |
| Records → file leaving CSRM | Only what the list or the released read discloses, through the list's own scope and repository; at most 10,000 rows, counted first and re-checked on a cap + 1 read; every text cell and header neutralised; an XLSX text cell at most 32,767 characters; an attachment, never sniffed or cached. | Rows of the 14 views, About sheet |
| Export and import → log platform | One closed, JSON-encoded line per export attempt and per committed import; free text (search, filter values, sort, zone, file name, display name) loses C0 and C1 controls and bidirectional marks and is cut to 255 characters; never a cell or the raw query. | Actor, view, parsed filters, counts, digest |
| Upload → Strapi import reader | Untrusted bytes: at most 5 MiB measured on disk, `.csv` or `.xlsx` by extension and signature, strict UTF-8, ZIP bounds before any inflate, one 50 MiB inflate budget, macro and encryption refusals, the first sheet resolved as the reader resolves it and held to 1,024 columns and 5,000 rows; Strapi is the one parser. | CSV text, workbook parts, headers, cells |
| Commit form and error-report request → retained records | Decisions are a closed JSON field checked against the actor's own retained preview; tokens are 32 random bytes bound to the actor and collection for 5 minutes; an error report is rebuilt from the upload and Strapi's record after a SHA-256 match, with no client-supplied issues. | `previewDigest`, `resultToken`, `decisions`, the file |
| Strapi response → web → browser and file system | Server Actions validate with strict zod schemas; every file passes `exportFileRule` (type, the server's safe name, 64 MiB, BOM or PK signature) and a 0 to 10,000 row count; refusal details cross only as closed, bounded values cleaned of controls; text renders as React text. No Route Handler and no raw `fetch`. | File bytes, names, refusal details |
| Released record → paper | The report routes read through Strapi's released-assessment record-read check; the report model keeps active Risks only and is equal for both actors. | Released detail, active Risks, control implementations |
| Plan → published contract and grants | G-6: the pilot writes each dated approval line before any contract, grant or reason lands; no content type changes; both catalogue copies stay byte-identical. | Operations, Functions, reasons |
| npm registry → the backend | One new package, exactly pinned, with its one locked dependency. | `write-excel-file` 4.1.1, `fflate` 0.8.3 |
