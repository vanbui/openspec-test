## Review Fixes

Applied during review before commit:

- **Sticky identifier cell went translucent on hover.** The hover tint is an alpha colour, and replacing the cell's opaque surface with it let scrolled cells show through. The tint is now layered over the opaque surface as a background image; the unit assertion was updated to the new class.
- **State primitives drifted from the design direction.** Descriptions now use the secondary text colour (design direction §4 Empty states) rather than the muted one, the error icon uses the danger foreground (06.6-CONTEXT D-03), the icon is centred in default density, and default density restores the previous 48px vertical rhythm and prose-width description.
- **Scroll region label.** "…horizontal scroll region" became "…, scrolls horizontally", since assistive technology already announces the region role.
- **Static guard root path.** Run directly, the guard resolved feature files against `apps/web/scripts`; it now resolves against `apps/web`. Against current source it correctly reports the five surfaces not yet migrated, so real-source enforcement is wired into the unit suite by 06.6-06, the last migration.
