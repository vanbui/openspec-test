## Shared Patterns

- **Mutation wrapper:** serialise → transaction → `lockAssessment` row lock → load → the one guard → act → transition → history → `notify`, all inside the transaction (`releaseAssessment` above; 16-PATTERNS wrappers; 13-PATTERNS lock order request-then-assessment).
