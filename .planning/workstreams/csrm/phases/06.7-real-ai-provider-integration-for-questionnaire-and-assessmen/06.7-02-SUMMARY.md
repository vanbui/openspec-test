## Review Fixes (applied during orchestrator review, 2026-09-15)

1. **Module-load provider selection crashed assessment generation.** `assessment-workflow.ts` selected the active provider in a module-scope constant, but `assessment-draft-provider.ts` imports back into `assessment-workflow.ts`. Under the mounted harness the workflow evaluated that constant before a provider module had finished initialising, so `generateAssessment` read `.name` of `undefined` and every draft-generation route returned 500; eleven `assessment-workflow.integration` tests failed. The selection is now a function resolved at each call site. The focused suite passes 18/18. The earlier "full backend suite exited 0" result was not reliable evidence: the failures surfaced only when the complete output was read.
2. **Risk ordering disagreed with the parser.** The adapter sorted `risks` with `localeCompare`, while `parseAssessmentDraftProposal` requires plain string (code-unit) order, so mixed-case Risk Type names would fail valid provider output as `PROVIDER_OUTPUT_INVALID`. The adapter now sorts the way the parser checks, with a mixed-case regression test.
