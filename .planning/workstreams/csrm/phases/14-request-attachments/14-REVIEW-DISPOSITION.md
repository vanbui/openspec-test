# Phase 14 review disposition

The merged review (`14-REVIEW.md`, committed in `1c3bc451`, diffed from `e50053f`) is dispositioned here in stage B, under the pilot's rulings in `14-PILOT-RULINGS.md` (`279218be`, with the browser walk appended in `8ca61fa7`); a ruling overrides a lane's proposed fix. Every confirmed Critical and Warning, and every Info that is fixed in code, is fixed test-first: the new or corrected test was seen failing on the code before the fix and passing after it. Where the code was right and the finding was a test that could not fail, the corrected test was proven able to fail by breaking the guarded code once locally, and the code was then restored byte for byte (an empty `git diff` for that file). When a failing test shows a finding is not real, the row says "Not reproduced" with the test that proves today's behaviour. Every other Info has a disposition with its reason.

A row lists its commits in commit order: a `test(14)` commit holds tests and a `fix(14)` commit holds the fix, sometimes with its tests; `Fixed (test only)` means no production code changed (a docs commit may come with it). Test files are named without their folder: Strapi tests are in `apps/backend/tests/`, web unit tests sit beside their modules in `apps/csrm/src/`, and Playwright specs are in `apps/csrm/e2e/`. The before, after and break logs were kept outside the repository, in the stage B session's scratchpad, so this file records their results rather than linking them. The fix groups append their rows in finding order within their own rows; a finding fixed together with another names the group's shared commits.

All 93 findings of `14-REVIEW.md` (3 Critical, 37 Warning, 53 Info) have a disposition: 62 are fixed with a code change (WR-305 and IN-706's change is to `.gitattributes`, IN-505's is a compile-time guard, and WR-705's code half is in IN-209's commit), 20 are fixed test-only (WR-306 and IN-607 in the Strapi and Playwright harnesses), 10 are fixed in documents only (WR-701, IN-104 and IN-708, and Lane 7's WR-702 to WR-704, IN-701, IN-702, IN-707 and IN-709), and 1 is not reproduced (WR-501: the earlier detection pattern already admitted the underscore; contract item 4 still made it one pattern everywhere). None is accepted and none is deferred. A finding with several rows counts once, by its largest change. Of the pilot's 16 walk items, 14 are fixed with a code change and 2 need no change: O4, by the pilot's ruling (§2.2 is clarified), and D7, whose preload 404 is development-only (the production-build assertion stays as the guard). The fix groups ran in the order the rulings set (the two Critical fixes, the contract-change group, Lanes 1 to 7, then the walk), one group at a time, each proving its own rows.
