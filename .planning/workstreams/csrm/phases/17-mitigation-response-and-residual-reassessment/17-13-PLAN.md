## Phase Goal

**As a** Requestor or a nominated risk owner, **I want to** see the assessment once it is released for response and tell the analyst which controls we have or plan, and as a Security Analyst I want to nominate each risk's owner and have the AI reassess residual risk from the responses, **so that** the final assessment reflects the business's real mitigations and the people who must accept it have seen it.

This plan's slice: the second line decides what the first line proposed. An analyst adds a proposed control to the risk as a mitigation control, makes a proposed owner the risk owner, or rejects with a reason the participants read, and can undo while nothing has moved on.

<objective>

The narrowing of "every risk and control mutation is analyst-only" holds: only an analyst's decision writes a risk or control implementation (D-04).
Output: one service, one operation with its contract chain, the decisions in the rounds read, and the lapse hook.

## Recorded planning decisions

- **Service (`response-decisions.ts`).** `RESPONSE_DECISION_BATCH_MAX = 200`. `parseResponseDecisions(body)`: `{ decisions: [{ itemId, action: "accept" | "reject" | "restore", accept?: { controlId, controlStatus?, ownerId?, dueDate?, evidence?, effectivenessRating? }, reason? }] }`, 1 to 200, unique `itemId`s, closed; `accept` only with `action: "accept"`; else 400. `decideResponseItems({ strapi, assessmentDocumentId, actor, decisions })`: `withRequestLock` then the assessment lock; `assertAssessmentEditable` (not editable, round open, owner); every item on this assessment (else 404 for the whole batch); then per item in order: a `comment` → 400; an item on a withdrawn risk → 409 `RISK_WITHDRAWN`; an applied repeat → `unchanged`; a decided item and a different action other than `restore` → 409 `RESPONSE_ITEM_DECIDED`.
  - Accept `proposed-control`: `controlId` required (400); the values default to the proposal; `changed` lists the fields that differ (`controlStatus`, `ownerId`, `dueDate`, `evidence`); `reason` (1–500) required when `changed` is non-empty (400); the owner through `isEligiblePerson` (409 `OWNER_NOT_ELIGIBLE`); the library control already implemented on the risk → 409 `CONTROL_ALREADY_ON_RISK`; create through the inner creation path with `controlStatus`, `controlOwner`, `implementationDueDate` (Planned), `evidence`, `controlEffectiveness` (default `Not Assessed`); write the item's `decision: "accepted"`, `decidedValues`, `decisionReason`, `decidedBy`, `decidedAt`, `controlImplementation`, and `acceptedFingerprint` (SHA-256 of the created implementation's writable fields in a fixed key order); history row `sourceKind: "response"`, `proposalItem` the item's documentId.
  - Accept `proposed-owner`: `assertEligibleRiskOwner` (with the assigned analyst); set `riskOwner` through the inner risk update; `decidedValues { previousOwnerId }`; history `riskOwner` change with source `response`.
  - Reject: `reason` 1–500 required (400); `decision: "rejected"`, `decisionReason`.
  - Restore: accepted control → only when the implementation's current fingerprint equals `acceptedFingerprint`, then delete it through the inner path (history removal, source `response`) and clear the decision fields; accepted owner → only when the risk's `riskOwner` equals the accepted owner, then restore `previousOwnerId` (history); rejected → clear; anything else → 409 `RESPONSE_DECISION_UNDO_UNAVAILABLE`.
  - Every applied action appends `{ schemaVersion: 1, action, by, at, reason? }` to `decisionLog` (at most 50). The accepted-edit transition runs once when any accept or any restore of an accept applied. Returns `{ applied: [{ itemId, action, controlImplementationId? }], unchanged: [{ itemId }] }`.
  - `lapseUndecidedItemsForRisk(strapi, riskDocumentId, { by, at, withdrawalReason })`: every undecided item on the risk becomes `decision: "lapsed"` with a `lapse` log entry citing the withdrawal; called by `withdrawRisks` inside its transaction; reinstatement does nothing to items.
- **Rounds read.** `listResponseRounds` fills each item's `decision` with `{ decision, reason, decidedBy: { documentId, displayName }, decidedAt, changed, controlImplementationId, controlLabel }` (the control's number and name for an accepted control); a lapsed item appears only to analysts.
- **Contract.** Path `POST /v1/risk_assessments/{assessmentId}/response_decisions` (`response-rounds/decide-response-items`), components `ResponseDecisionRequest`, `ResponseDecision`, `ResponseDecisionAccept`, `ResponseDecisionResult`, `ResponseDecisionResponse`; `ResponseItemDecisionView` completed; errors 400, 403, 404, 409. Catalogue `function.response_rounds.decide_api` (`Response Decisions API`, human Security Analyst only, `.api.01` `Decide Response Items`); the literal in `HUMAN_ANALYST_ONLY_OPERATIONS` and its mirror; the matrix row `humanAnalystOnly(200)` with a mounted proof and persistence guards on items, risks and control implementations (`riskOwner` 403).
