## Recorded planning decisions

- **Capabilities.** `capabilities` drops `administration:manage` and adds `reference-data:read`, `reference-data:manage`, `configuration:manage`, `access-review:read`. Anchors: `reference-data:read` the four `GET:/api/v1/{risk_types|controls|information_systems|information_assets}`; `reference-data:manage` the four `POST:` creates; `configuration:manage` `GET:/api/v1/configuration_settings`, `GET:/api/v1/divisions`, `GET:/api/v1/shared_views`; `access-review:read` `GET:/api/v1/role_holders`, `GET:/api/v1/configuration_changes`. Development grants: `Security Analyst` gets `reference-data:read` in place of `administration:manage`; `Admin` gets the Requestor's plus the four new ones.
- **Navigation.** `adminNavigationProfile` = the Requestor's sections, then `Reference data` (the four items, `reference-data:read`, icons `Layers`, `SlidersHorizontal`, `Server`, `Database`), then `Administration` (`Configuration` `/app/admin/configuration` `Settings2`, `Divisions and units` `/app/admin/divisions` `ListTree`, `Shared views` `/app/admin/shared-views` `Share2` with `configuration:manage`; `Role holders` `/app/admin/role-holders` `UserCog`, `Change log` `/app/admin/change-log` `ScrollText` with `access-review:read`). `navigationProfileFor(granted)`: `assessment:review` → the analyst profile, plus the Administration section when `configuration:manage`; else `configuration:manage` → the Admin profile; else the Requestor profile. The analyst's Reference data items move to `reference-data:read`. The pages behind the Administration items arrive in 22-19 to 22-23.
- **Reference routes.** List and detail gate on `reference-data:read` (else the state titled `You don’t have permission to view reference data` with UI-SPEC §2's description and `Go to Home`); new and import gate on `reference-data:manage` (else `You don’t have permission to change {plural}`, `{plural} are maintained by the Admin. You can read and export them.`, `Back to {plural}`); a Strapi 403 renders the same state; the check runs before any read; metadata keeps the static title.
- **Workspace.** `AdministrationWorkspace` takes `canManage` (from `reference-data:manage`): without it, no `Create {singular}`, `Import`, `Edit {singular}` or Retire controls are drawn and the list description gains ` Maintained by the Admin. You can read and export it.`; Export stays for both.
