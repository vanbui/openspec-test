## Recorded planning decisions

- **Service, schema, actions.** `shared-views-service.ts` (`import 'server-only'`): `listSharedViews(query)`, `renameSharedView(id, { name, expectedUpdatedAt })`, `unshareSharedView(id, { expectedUpdatedAt })`, `restoreSharedViewSharing(id, { undoOf })`, `transferSharedView(id, { ownerId, expectedUpdatedAt } | { ownerId, undoOf })`, registered for parity; closed parsers; `'use server'` actions returning the item and `meta.changeId`, which the Undo of unshare and transfer sends as `undoOf`.
- **Component.** `SharedViews`: UI-SPEC §8's table, filter chip, dialogs (`Rename`: 480px, `Save view`; `Transfer “{name}”`: `New owner` person picker of active Security Analysts, others `aria-disabled` with `Not an active Security Analyst`, hint, `Transfer view`, `Cancel`), Undo toasts `Renamed the view to “{name}”.`, `Stopped sharing “{name}”. It’s {owner}’s personal view again.`, `Transferred “{name}” to {new owner}.`; `SHARED_VIEW_CHANGED` and 404 render AA3's `“{name}” changed since this page loaded. Refresh the page to see it now.` with `Refresh page`; `VIEW_OWNER_NOT_ELIGIBLE` renders AA3's field message.
- **Route.** `/app/admin/shared-views`, gated by `configuration:manage` before any read; title `Shared views | IdamBox CSRM`.
- **Forward effect.** `review-panel.tsx` renders, after an item's line, `Follows the current risk appetite.`, `Follows the current rating bands.` or `Follows the current peer review setting.` from `follows`; `No executive approver needed` lists `{k} {risk names|risks name} an executive approver the current risk appetite no longer needs.` with an outline small `Clear` (name `Clear the executive approver on {risk number}`) calling 17.1's executive approver action with `approverId: null`, optimistic, with the Undo toast `Cleared the executive approver on {risk number}.` re-naming the cleared approver. `acceptance-round-panel.tsx` renders `This round follows the risk criteria as they stood when it opened on {date}.` `The next submission uses the current criteria.` in `--text-caption` when `criteriaDifferFromCurrent`. `files-section.tsx` renders `Files are kept for {n} years after the request closes.` from `meta.retentionYears`.
