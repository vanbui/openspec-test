## Recorded planning decisions

- **Suggestion state table** (`applySuggestionDecision`, pure, in `ai-proposal-decisions.ts`). Accept: `proposed` → `added` with a Planned implementation and its snapshot (content change); `present` or `added` → no-op; `dismissed` → 409 `AI_PROPOSAL_ALREADY_DECIDED`. Dismiss: `proposed` → `dismissed` (no content change); `dismissed` → no-op; `added` → 409. Restore: `dismissed` → `proposed` (no content change); `added` → removes its implementation when unchanged, else 409 `AI_SUGGESTION_CONTROL_CHANGED` (content change); `proposed` → no-op. An unknown suggestion key → 400. `present` is derived at read time (12-09) when the control is already a mitigation control on the risk.
- **Shared control-implementation helpers.** `createControlImplementationWithinMutation(strapi, { riskDocumentId, assessmentDocumentId, body })` and `removeControlImplementationWithinMutation(strapi, { implementationDocumentId, riskDocumentId, assessmentDocumentId })` hold the validation and writes the public functions already perform; the public `createRiskControlImplementation` and `deleteControlImplementation` call them inside their own `withMutableAssessmentMutation` (no nested mutation, which would deadlock on the serialisation queue). `controlImplementationWritableSnapshot(implementation)` returns the writable fields compared for "unchanged".
- **Action.** `decideAiProposalsAction(input)` in `ai-assistance-actions.ts`: strict input (assessment id and 1 to 200 decisions), one `decideAiProposals` call, `revalidatePath('/app/review/assessments/' + encodeURIComponent(assessmentId))`, returns `{ ok: true, data }` or a failure carrying `status` and `reason`.
- **Copy.** `aiDecisionRefusalCopy(failure)` in `refusal-copy.ts` returns `{ text, kind }` for family J: UI-SPEC §6.3's seven rows, UI-D12's copy for `AI_SUGGESTION_CONTROL_CHANGED`, and the G-14 addition. The addition follows family J's voice (what happened, so what follows, then the next step) and uses the "Confirm" wording of UI-D1; it is not in the UI-SPEC's table and is recorded here as an addition (2026-10-01 confirmation). "Accept" in it names the treatment action value, as §3.5's notes do.
