## Recorded planning decisions

- **Folder shape.** `csrm-ai-run` follows the minimal content-type pattern of `csrm-risk-type`: `factories.createCoreService`, `factories.createCoreController`, and `factories.createCoreRouter(..., { only: [] })`, so the type mounts no route; plan 12-10 adds the one custom read route.
- **Relations.** `initiatedBy`, `assessmentRequest`, `questionnaire`, `assessment` and `risk` are one-way `manyToOne` relations (no inverse attribute on the targets, so no other schema file changes). `assessmentRequest` is required in code by `createRunningAiRun`, not in the schema.
- **Interrupted runs** get `status: "interrupted"` and `completedAt` set to the reconciliation time; `failureCode` and `failureMessage` stay null.
- **Errors.** `AiRunRecordError` (status 409, closed message) for a bound or an append that would rewrite history; envelope parsers return null and never throw.
- **Harness helpers.** `createAiRunFixture(data)`, `getAiRun(documentId)`, `appendAiRunDecisionsFixture(runId, events)` and `reconcileInterruptedAiRunsFixture()` call the service on the running instance.
