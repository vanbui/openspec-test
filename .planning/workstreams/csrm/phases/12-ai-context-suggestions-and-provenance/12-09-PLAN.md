## Phase Goal

**As a** Security Analyst, **I want to** have the AI work from everything the Requestor gave and show where each proposal came from, **so that** I can trust, check and correct its output quickly.

This plan's slice: the assessment reads tell the analyst who generated the draft, with which provider and run, which values are still AI proposals, where each statement came from and what controls the AI suggested, and tell the Requestor only that AI assisted.

<objective>
Project the assessment's `generation` facts and the assessment's and each risk's `aiProvenance` to the analyst (D-21, D-23, D-25), resolving actors, controls and citation labels in bounded reads, and `aiAssisted` to the Requestor (D-23), with the specification, generated client, closed parsers and parity guard in the same plan (D-02).

Purpose: INT-06 criteria 1 and 2 and ASSESS-08 criterion 2 need these facts at the editor; UAT-032.
Output: actor-aware projections and the contract change. The editor renders them from plan 12-15.

Edits Strapi source? Yes. Changes the specification? Yes. Runs Playwright? No.
</objective>

## Recorded planning decisions

- **Components** (all closed): `AiSourceCitation` = `{ key, kind: "request" | "answer" | "system" | "asset", label, section: string | null, classification: string | null }`; `AiFieldReview` = `{ field, state: "proposed" | "accepted" | "edited", by: ActiveUserSummary | null, at: string | null, sources: AiSourceCitation[] | null }` (sources only on statement fields); `AiSuggestionReview` = `{ key, control: ControlSummary, rationale, state: "proposed" | "added" | "dismissed" | "present", by: ActiveUserSummary | null, at: string | null, implementation: string | null }`; `RiskAiProvenance` = `{ runId, proposalKey, fields: AiFieldReview[], uncitedClaims: string[], suggestions: AiSuggestionReview[], adjustments: string[], outstanding: integer }`; `AssessmentAiProvenance` = `{ runId, fields: AiFieldReview[], adjustments: string[], outstanding: integer }`.
- **Where they appear.** `AnalystAssessmentDetail.generation: AiGenerationFacts | null` and `AnalystAssessmentDetail.aiProvenance: AssessmentAiProvenance | null` (both required, nullable); `AnalystRiskDetail.aiProvenance: RiskAiProvenance | null` (required, nullable); `RequestorReleasedAssessmentDetail.aiAssisted: boolean` (required). Every producer of a changed component (grep the spec for each `$ref`) changes in this plan.
- **aiAssisted** for the assessment is true when it has `generatedDate` and a `providerName`.
- **Unknown citation key** (a key missing from the run's catalogue, or a run that cannot be read): projected with `kind` from the key's prefix and `label` `Source no longer available`; never a read failure.
- **Bounded reads.** One query for every distinct run id on the assessment, one for every distinct actor documentId, one for every suggested control documentId.
