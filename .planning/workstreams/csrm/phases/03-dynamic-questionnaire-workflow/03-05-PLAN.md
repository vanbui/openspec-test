## Trust Boundaries
| Boundary | Description |
|---|---|
| PATCH/POST body → workflow service | Answer keys/values and all extra fields are untrusted. |
| Persisted definition → validation | Stored JSON may be malformed or adversarial and must fail closed. |
| Multi-record submit → database | A partial write would corrupt the workflow. |
