**As a** Requestor, **I want to** complete data-defined questionnaires for my authorised requests over time and submit them when valid, **so that** Security Analysts receive the structured context they need to review and assess risk.

<objective>Deliver the complete Requestor fill, draft/resume, validation, and confirmed submit slice with one reusable renderer.

Purpose: Turn authorised data-defined questions into a guided, recoverable workflow without embedding domain rules in JSX.
Output: Shared renderer, Requestor detail page/states, and comprehensive component tests.</objective>

|---|---|

| RHF values → Server Action | Browser validation is advisory; values remain untrusted. |

## STRIDE Threat Register
| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-03-03 | Tampering | form values | mitigate | Closed RHF schema and answer-only action shape; server owns metadata. |
| T-03-04 | Tampering | conditional requiredness | mitigate | Shared client engine gives feedback; server independently recomputes. |
| T-03-06 | Information Disclosure | hidden/submitted UI | mitigate | Hidden values unregister/clear; permission states render no data; submitted controls removed. |
| T-03-07 | Tampering | File upload control | mitigate | Explicit unavailable alert; no text/URL fallback; active required upload blocks. |
