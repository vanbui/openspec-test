## Shared Patterns

- **Authorisation chain:** standalone router + `global::csrm-app-enabled` + `global::csrm-authorization` with an operation constant and a scope flag; scope read only from `ctx.state.csrmAuthorization` (route and controller analogs above). Apply to all three operations.
- **Actor-neutral errors:** `safeError` 400/403, 404 for unseen ids, no titles echoed (`LEAK_PATTERN`). All controllers.
- **Transactions:** Document Service writes join the ALS transaction; raw knex always `.transacting(trx)`; row lock shape from `assessment-workflow.ts:715-722`. All event hooks and mark paths.
- **Closed vocabularies:** `as const satisfies Record<…>` + `Map` lookup (`request-status-summary.ts:34-45`). Kinds, parts, views, page sizes.
- **Server words, web formats:** `request-lifecycle.ts:42-62`. Projection + web schema destination allow-list.
- **Typed web layer:** `'server-only'` service with `responseParserModule`, `'use server'` actions, zod-free domain module for clients.
- **Counts without polling:** 11-13's unawaited promise in `<Suspense fallback={null}>`; failure renders nothing.
- **On-demand overlay:** 11-19's `next/dynamic` + prefetch + guard `navigate`.
