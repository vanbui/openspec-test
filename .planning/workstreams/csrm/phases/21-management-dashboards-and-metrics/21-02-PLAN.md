## Phase Goal

**As a** risk manager or leader, **I want** trends, ageing, cycle times and a heat map, **so that** I can see whether risk and the assessment process are improving.

This plan's slice: every rule behind a Phase 21 figure, as pure functions proven by unit tests before any table or route exists: the stage a request is in, the working days it has waited, the median and 90th percentile of a sample, the open released risks at a month end, the heat-map cells, and failed AI jobs with their recovery and outcomes.

- **`working-days.ts`.** `workingDaysBetween(enteredDate, today, week = WORKING_WEEKDAYS)`: count of dates `d` with `enteredDate < d ≤ today` whose UTC weekday is in `week`. `workingDayCutoff(today, k, week)` per 21-RESEARCH's example. `ageBandCutoffs(today)` → `{ c2, c5, c10 }` as UTC dates; `ageBandOf(workingDays)` → `0-2` | `3-5` | `6-10` | `over-10`; `calendarDaysSince(enteredDate, today)` (whole days, D-17).
- **Constants (`insight-constants.ts`).** `AGEING_BAND_BOUNDS = [2, 5, 10]`, `AGEING_BANDS = ["0-2", "3-5", "6-10", "over-10", "not-recorded"]`, `WORKING_WEEKDAYS = [1, 2, 3, 4, 5]`, `STAGE_PERCENTILE_MIN_SAMPLE = 10`, `SLOWEST_ITEMS_LIMIT = 5`, `REPORT_TOP_N = 10`, `TREND_PERIODS = [6, 12]` with `TREND_DEFAULT_PERIOD = 12`, `TREND_RISK_CAP = 5_000`, `TREND_HISTORY_ROW_CAP = 25_000`, `TREND_ID_CHUNK = 1_000`, `AI_FAILED_WINDOW_DAYS = 7`, `AI_HEALTH_RUN_CAP = 5_000`, `AI_FIELD_SAMPLE_CAP = 1_000`, `REPORT_RECORDS_PAGE_SIZES = [5, 10, 25, 50]`, `REPORT_RECORDS_DEFAULT_PAGE_SIZE = 25`; each with a one-line JSDoc and `Object.freeze([...] as const)` like `THROUGHPUT_PERIODS`.
- **`stage-statistics.ts`.** `elapsedDaysSample(pairs, cap)` → `{ days: number[] (sorted ascending), sampleSize, truncated }` with `medianDays`'s drop rules; `nearestRank(sorted, p, minimum)` → `sorted[Math.ceil(p * n) - 1]` rounded to one decimal, or null below `minimum`; `stageStatistics(pairs, cap)` → `{ medianDays, p90Days, sampleSize, truncated }`. `pairEpisodes(rows)` turns one request's rows ordered by `sequence` into `{ stage, enteredAt, leftAt, durationDays, roundDocumentId, requestDocumentId }` episodes (the last row has no episode). `report-math.ts`'s `medianDays` returns the same `{ value, sampleSize, truncated }` computed from `elapsedDaysSample`.
- **`trend-as-at.ts`.** Inputs `TrendCandidate = { riskDocumentId, riskNumber, liveResidualRating, approvalDate: Date, closureDate: string | null }` and `TrendHistoryRow = { riskDocumentId, kind, occurredAt: Date, changes: unknown }`. `foldRiskAsAt(candidate, rows, instant, today)` → `{ counted: false } | { counted: true; rating: RiskRating | "notRated" }` per 21-RESEARCH R6 (a future `closureDate` with no row counts from `min(closureDate, today)`); `foldTrend(candidates, rowsByRisk, months, today)` → `{ available: true; points: { monthStart, counts: RatingCounts }[] } | { available: false }`, folding complete months only (the partial month is the live point, set by the caller).
- **`heat-map-fold.ts`.** `HEAT_MAP_SIDES = ["inherent", "residual"]`; `foldHeatMap(rows)` over `{ inherentLikelihood, highestInherentConsequence, residualLikelihood, highestResidualConsequence, withdrawnAt }` → per side `{ cells: { likelihood, consequence, band, count }[] (25, every cell present), offScale: { likelihood, consequence, total } }`, where `band` is `deriveRating(likelihood, consequence)` and a value whose reading is not `on-scale` counts in `offScale` for its axis (a risk off on both axes counts once in `total`).
- **`ai-run-groups.ts`.** `AI_FAILED_STATUSES = ["failed", "interrupted"]`; `failedWindowStart(today)` → `utcDateToInstant(addUtcDays(today, -(AI_FAILED_WINDOW_DAYS - 1)))`; `groupRunsByJob(runs)` keyed `${operation}\u0000${jobId}` (a null `jobId` is its own group); `recoveryOf(run, groupRuns)` → `"completed-on-retry"` when a `completed` run of the group has a higher `attempt` and the run is `failed`, else null; `runOutcomeOf(run, { laterCompletedForTarget, targetReleased })` per 21-01's record 2 order; `foldAiHealth(runs, months)` → per month `{ runs, failedOrInterrupted, failureRate }`, by `(operation, providerName)` `{ completed, failed, interrupted, failureRate }`, outcomes `{ confirmed, edited, dismissedOrRejected, lapsed, stillProposed }`; `editShareOf(fields, cap)` → `{ share, sampleSize, truncated }` over `{ state, at }` values newest first.
