## Pattern Assignments (only what earlier maps do not give)

### Every contest write: serialise, transaction, row lock — `B/src/api/csrm-assessment/services/assessment-workflow.ts` 381-405, 430-460

Contest services do **not** call `withMutableAssessmentMutation` (it runs `assertMutableAssessment` and the accepted-edit transition, and an answer is not a content edit, D-08). Export and reuse the two inner pieces instead:
```typescript
async function serializeAssessmentMutation<T>(strapi, documentId: string, work: () => Promise<T>): Promise<T> { /* per-strapi, per-document promise queue */ }

async function lockAssessment(strapi, documentId: string, transaction: unknown): Promise<void> {
  const query = strapi.db.queryBuilder("api::csrm-assessment.csrm-assessment");
  query.select(["id"]); query.where({ documentId }); query.forUpdate(); query.transacting(transaction);
  await query.execute<unknown>();
}
// usage shape (withMutableAssessmentMutation 443-446):
return serializeAssessmentMutation(strapi, assessmentDocumentId, async () =>
  strapi.db.transaction(async ({ trx }) => {
    await lockAssessment(strapi, assessmentDocumentId, trx);
    // load assessment; released → 409 ASSESSMENT_NOT_MUTABLE; compare round / expectedSequence; write entry + cached status; notify
  }));
```
17.1 may already export these for its review and decision services (17.1-PATTERNS Shared "Mutation wrapper"); re-locate before adding a second export.
