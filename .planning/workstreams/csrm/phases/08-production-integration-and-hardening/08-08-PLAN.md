## Recorded planning decisions

- **The shared primitive is a hook plus a small wrapper**, `useHorizontalOverflow(scrollerRef, deps)` returning `{ overflowing, atEnd }` and `horizontalScrollRegionProps(label, overflowing)`; DataTable keeps its own scroller element (it owns the sticky header and cell classes) and the cross-tab keeps its own wrapper, so no markup moves between files. The small wrapper is `HorizontalScrollRegion({ label, className, children })`, a `div` that owns its ref and the hook and spreads the region props: the CSV import flow wraps each of its three tables in it, because those wrappers mount conditionally by step and a hook cannot be called conditionally.
- **The fade is CSS keyed on data attributes, not a scripted overlay:** `[data-overflow="true"][data-overflow-end="false"]::after` draws the end-edge fade from transparent to `var(--surface)` over `var(--table-scroll-fade-width)` with `pointer-events: none`; the hook toggles `data-overflow-end` on `scroll` (`scrollLeft + clientWidth >= scrollWidth - 1`). No transition (UI-SPEC Motion table).
- **`min-w-56` (14rem) and `max-w-md` (28rem)** are the Tailwind utilities that carry the X-3 bounds, so no arbitrary value appears in feature code; the direction document records the rem values.
- **`scroll-padding-inline-start`** is set on the scroller to the measured sticky column width through a CSS custom property (`--table-sticky-inline-start`) the hook updates, so a focused cell is never hidden under the sticky column (SC 2.4.11, UI-SPEC §5.4).
- **Geometry proofs stay in the specs that own the surfaces:** the register (768, 1024, 1440) and Alerts (768) in `risk-register-workflow.spec.ts`; the administration lists and the four `/import` pages at 375 in `administration-workflow.spec.ts` (`region` present only while overflowing across its sweeps; no page overflow; the template button inside the viewport); the cross-tab fade at 375 in `analyst-insights.spec.ts` (its existing cross-tab block at lines 366-378).
- **The CSV import tables join D-29 through the wrapper, and the `ui/table.tsx` container stops scrolling (plan check finding (a), 2026-09-25):** `Table` renders inside `div[data-slot="table-container"]` with `relative w-full overflow-x-auto`, so at 375px the Guidance table produced an unlabelled, unfocusable inner scroller that axe reports as `scrollable-region-focusable` on the controls, information-systems and information-assets import pages. `HorizontalScrollRegion` always carries `[&>[data-slot=table-container]]:overflow-visible` (the DataTable scroller's existing technique), so the wrapper is the only scroller; the region names are the tables' own labels (`{Label} CSV columns`, `{Label} import preview`, `{Label} import results`) plus `, scrolls horizontally`. No sticky column: these are plain `Table` cells with no identifier-column contract.
- **The template button reads `Download CSV template` on all four import pages (plan check finding (b), 2026-09-25):** `Button` is `whitespace-nowrap`, and `Download Information Systems CSV template` / `Download Information Assets CSV template` overflowed the 375px viewport (document `scrollWidth` 377 and 391); the `Import {Plural} from CSV` heading names the collection. Recorded as the UI-SPEC §11 addendum; no existing unit or E2E test asserts the old label (grep, 2026-09-25), so Task 2 adds the assertion rather than changing one.
- **File count accepted under D-49 (plan check, 2026-09-25):** the plan lists 19 files, above the 15-file guideline, because its edits are mechanical multi-site changes of one kind (every scroller on the shared region primitive, and the assertions that follow) and the executor runs with a large context; it is not split, and one owner per file per wave still holds.
