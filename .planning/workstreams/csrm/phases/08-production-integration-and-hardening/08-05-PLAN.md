## Recorded planning decisions

- **Matrix layout (planner's discretion, per research §F4.2):** each row is `{ operation: '<METHOD>:/api/...', family: '<name>', request: (f) => ({ path, init }), expect: { owner, other, analyst, serviceAgent, noIdentity, noToken }, persistence?: (f) => Promise<unknown[]>, provenBy?: string[] , exercisesAllowed?: boolean }`. `f` is the seeded fixture bundle (harness identities, `requests`, `questionnaires`, `releaseFacts`, administration ids). The test issues every request whose expected status is not 2xx (denials are always safe to issue) and issues the 2xx request only when `exercisesAllowed` is true (rows whose success would consume a one-shot fixture cite `provenBy` instead). `provenBy` entries have the form `<file>.test.ts › <test title>` and the test asserts the file exists under `apps/strapi/tests` and contains the title.
- **Actors:** `owner` = harness `owner` (Jane's role: the seeded Requestor), `other` = `other` (the Secondary Requestor role, Maya's counterpart), `analyst` = `analyst` (Bob), `serviceAgent` = `service-agent`, `noIdentity` = no `x-csrm-test-identity` header, `noToken` = analyst identity with `omitApiToken: true`. The `agent` and `inactive` identities stay in the existing per-family proofs and are not matrix columns (D-16 names five actors; the token column is the research's addition for D-51).
- **Plugin rows:** `POST /api/auth/local/register` (well-formed body), `POST /api/auth/local` (well-formed body) and `GET /api/users/me` are rows keyed to `pluginRoutes`, with `noIdentity` expectations set from the observed statuses (registration is disabled by plan 08-03) and recorded as the D-37 residual.
- **The forced internal error has two proofs:** the harness middleware (D-38) and the existing injected write failure in `assessment-workflow.integration.test.ts` around line 1387, extended to assert the envelope, so the proof does not rest on test-only plumbing alone.
- **Runtime budget:** the matrix file is expected to take 2-4 minutes (research A5); it is one file, so it runs serially like every other Strapi file.
