## Assets
- Request contents/relations, ownership, server number, draft state, submittedDate, and one-way workflow integrity.
## Trust Boundaries
| Boundary | Description |
|---|---|
| Browser form → Server Action | Form values, relation IDs, documentId, and submit intent are untrusted. |
| Server Action → typed Strapi service | Revalidated allowed data crosses to the authoritative API. |
## STRIDE Threat Register
| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-02-01 | Spoofing | action identity | mitigate | Action cannot accept identity; server transport supplies it. |
| T-02-02 | Tampering / Information Disclosure | form bodies/detail IDs | mitigate | Closed Zod fields, generated bodies, 403 state, Strapi owner/mass-assignment enforcement. |
| T-02-03 | Tampering / Repudiation | submission | mitigate | Server revalidation, explicit confirmation, pending lock, one-way backend guard, returned timestamp/status. |
| T-02-04 | Information Disclosure | relation selectors | mitigate | Only policy-protected CSRM system/asset reads; no sponsor/IAM lookup. |
| T-02-SC | Tampering | packages | mitigate | No install. |
</threat_model>
