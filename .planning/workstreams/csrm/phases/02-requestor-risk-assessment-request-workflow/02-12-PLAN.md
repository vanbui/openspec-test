<threat_model>
## Assets
- Request fields/relations, server-owned ownership/number/status/date facts, and safe mutation errors.
## Trust Boundaries
| Boundary | Description |
|---|---|
| Browser/action input → shared Zod schemas | All submitted field values, relation IDs, document IDs, and workflow intent are untrusted. |
| Server Action → typed Strapi service | Only revalidated allowlisted data may cross to generated operations. |
## STRIDE Threat Register
| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-02-01 | Spoofing | action identity | mitigate | Actions accept no identity; server transport supplies it. |
| T-02-02 | Tampering / Elevation | mutation bodies | mitigate | Closed schemas and exact generated-body assertions exclude server-owned fields. |
| T-02-03 | Tampering / Repudiation | submit action | mitigate | Server revalidation sends only submitted intent; Strapi transition remains authoritative. |
| T-02-04 | Information Disclosure | inventory/sponsor reads | mitigate | Only authorised CSRM system/asset reads; no generic sponsor/IAM operation. |
| T-02-SC | Tampering | packages | mitigate | No package install. |
</threat_model>
