# Phase 06.2 Plan 03: Questionnaire Generation Web Boundary Summary

Added a typed server-action boundary and an accessible, bounded questionnaire-generation lifecycle to submitted assessment-request review.

## Delivered

- Added closed schemas for queued, running, completed, and failed questionnaire-generation jobs, including provider provenance and a required populated questionnaire relation on completed results.
- Added generated-client-only start, status, and retry services plus strict server actions that reject browser-supplied provider or identity fields and revalidate only after authoritative success.
- Added a responsive client lifecycle with one request in flight, terminal cleanup, a 30-second polling bound, recovery through Check again, polite state announcements, failure retry, and existing-questionnaire replacement confirmation.
- Rendered the action for submitted requests even when no questionnaire relation exists, and linked completed work to the existing questionnaire review route.
- Added service/action/detail regression coverage for relation requirements, hostile action fields, and submitted requests without a questionnaire.
