# Phase 06.2 Plan 01: Questionnaire Generation Tracer Summary

Implemented an actor-scoped, deterministic questionnaire-generation job workflow with durable questionnaire provenance and shared domain numbering.

## Delivered

- Added queued generation, actor-scoped status, and failed-job retry routes with separate API-only catalogue Functions granted only to `role.security_analyst`.
- Added a closed provider parser, deterministic request-context proposal provider, active-only registry deduplication, bounded terminal retention, and safe failure projection.
- Added `CsrmQuestionnaire.generatedDate` and `generatedBy`, populated in the same transaction as generated question persistence. Regeneration preserves the questionnaire document ID, number, and request relation while replacing question rows.
- Added QNR allocation through `createWithDomainNumber`, including unique-conflict retry semantics.
- Updated the published OpenAPI contract and regenerated the typed web declaration.
