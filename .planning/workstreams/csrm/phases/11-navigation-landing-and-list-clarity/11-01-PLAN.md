## Phase Goal

**As a** Requestor or Security Analyst, **I want to** have a sectioned sidebar and a Home that leads with my next action, **so that** I always know where my work is and what to do next.

This plan's slice: a released request reads "Released" wherever a request status is shown, through one status mapping that later phases extend, and the design direction carries the five patterns the rest of the phase builds on.

## Recorded planning decisions

- **One mapping (G-13 seam).** `statusPresentation` in `apps/csrm/src/components/csrm/status-badge.tsx` already calls itself "the one mapping" (08 D-27) and owns the assessment labels (`assessment-domain.ts` defers to it). The request family had a second, label-only map, `requestStatusPresentation` in `request-domain.ts`, whose `order` field nothing reads. It is deleted; callers use `statusLabel('request', status)` and keep `requestStatuses` for order. Phase 17.1's "Closed" work then changes one entry (`closed` already exists with the label `Closed`).
- **Fallback.** `presentationOf` returns the family entry when one exists, otherwise `{ icon: CircleIcon, label: <the value in sentence case with hyphens as spaces>, tone: 'neutral' }`. Closed parsers refuse unknown values at the boundary today, so the fallback is a guard for a value added to a vocabulary before its label, never a way to show raw data. `statusLabel` returns the same label.
- **Extension placement.** X-6 is appended to `### AppShell / sidebar`, X-7 to `### Buttons`, X-8 to `### Dialogs`, X-9 becomes a new `### Lifecycle stepper` heading placed directly before `### Dialogs`, and X-10 is appended to `### Record links` after its "Block links" bullet. Each is one bullet holding the UI-SPEC's "Exact wording to record" verbatim (without the surrounding quotation marks). Nothing else in the direction changes.
- **Glossary sentence (UI-SPEC §10).** In the `Released (Risk Assessment status)` entry, the paragraph that begins "Only the displayed label changes." becomes: `Only the displayed label changes. The stored value `approved` and the `status=approved` query value are unchanged, and a request whose stored status is `approved` (`CsrmRequestStatus`) also reads "Released".` The `Closed (Assessment Request status)` entry is unchanged.
