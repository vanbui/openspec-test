This plan's slice: every number on a report opens the records it counts.

## Recorded planning decisions

- **Table data.** `ReportTableRow` (and `ReportTableRowData`) gain optional `header?: { href: string; accessibleName: string }` and `cells?: readonly ({ href: string; accessibleName: string } | null)[]` aligned with `values`; `ReportTable` renders a `RecordLink` around a non-zero figure that has a cell link and around a header label that has a header link; existing callers pass neither and render as today.
- **Month ranges.** A month cell's range is the month's first day to its last day (or today for the current month), from the server's month buckets, as `YYYY-MM-DD`; the period tiles use `periodStart` to `today`.
- **The audit.** `figure-link-audit.test.ts` builds each report's presentation from a fixture with every count above zero, and the analyst and Requestor Home presentations likewise, then walks every tile, row, cell and chip: each has an href, or its key is in an `exceptions` map whose value cites `D-37` or `D-36` or is the documented plain `Not provided` implementation-status row (no list holds Risks with an unrecorded mitigation-control status; Phase 18 owns that table). A second pass with zero counts asserts zero cells and chips carry no href.
- **Names.** Built by one helper per pattern in `report-presentation.ts`; singular and plural written out.
