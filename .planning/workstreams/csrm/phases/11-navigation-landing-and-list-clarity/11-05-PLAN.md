## Phase Goal

This plan's slice: each actor's sidebar and phone drawer are divided into sections named by job, with the analyst's own requests tucked into a collapsed section.

## Recorded planning decisions

- **Profile choice on the client.** `CapabilityNavigation` (a Client Component) calls `navigationProfileFor(granted)` itself, because the profile holds icon components that cannot cross the server-to-client boundary as props; `granted` (a `Set`) already does.
- **Open rule (UI-D7).** The collapsible section's state starts `!defaultCollapsed || containsActive`, where `containsActive` is whether `activeNavigationHref(pathname, profileItems(profile))` is one of its items; an effect on `pathname` sets it open when that becomes true and never sets it closed. The state lives in component memory only.
- **Markup (X-6, UI-SPEC §1.2).** The primary action is a `Link` with class `nav-primary-action` placed first inside `<nav aria-label="Primary navigation">`. Each labelled section is `<div role="group" aria-label={label}>` with the existing `micro-label` heading and `border-sidebar-border` divider. The collapsible section renders a `button` with class `nav-section-toggle`, `aria-expanded`, `aria-controls={groupId}` and a 16px `ChevronRight` or `ChevronDown` before the label, then `<div role="group" id={groupId} aria-label="My own requests" hidden={!open}>` whose items render only while open.
- **CSS (X-6, values only from the direction).** In `apps/csrm/app/globals.css`, beside `.nav-link`: `.nav-primary-action` (full width, `--radius-full`, `--color-bg-page` fill, `--color-text-primary`, `--text-button`, `--shadow-button-light`, hover `translateY(-1px)` with `--shadow-button-light-hover` at the §5 button hover duration and ease, the inverse focus ring, the §4 button default height from 768px and the touch-target height below it) and `.nav-section-toggle` (the nav item height, `--radius-md`, the item hover fill, the inverse focus ring, the `micro-label` text). Reduced motion removes the lift.
- **Prefetch (UI-D8).** Items in the `reference-data` section render with `prefetch={false}` and call `router.prefetch(item.href)` on `onPointerEnter` and `onFocus`.
- **E2E helper.** `openFromNavigation` expands a collapsed section first when the named link is inside one (find the `button` whose `aria-controls` group would hold it, by section name argument or by trying the `My own requests` toggle when the link is not visible).
