## Phase Goal

**As a** Security Analyst, **I want** an assessment's risks in a table I can edit, copy and paste like Excel or a SharePoint list, **so that** reviewing and updating many risks takes minutes rather than a long scroll.

This plan's slice: the spreadsheet round trip in the browser, and the phase proved. A Security Analyst exports the current view and imports a corrected file back through a preview; then every gate runs.
