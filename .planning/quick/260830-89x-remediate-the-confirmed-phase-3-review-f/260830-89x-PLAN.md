## Trust Boundaries

| Boundary | Description |
|---|---|
| Browser form -&gt; Server Action -&gt; Strapi | Empty controls and validation failures cross two schemas and must retain safe, locatable meaning. |
| Persisted Strapi JSON -&gt; read projection | Admin-authored empty or malformed definitions are untrusted and must not expose data or fail unrelated authorised reads. |
| Actor identity -&gt; questionnaire mutation | A denied analyst/requestor write must be side-effect free, not merely return 403. |
| Questionnaire answer transaction -&gt; assessment-request lifecycle | Submitted answers and the owning request status must commit or roll back together. |
| URL query -&gt; authorised collection | Pagination input must be allowlisted and bounded while Strapi remains the authorisation boundary. |
