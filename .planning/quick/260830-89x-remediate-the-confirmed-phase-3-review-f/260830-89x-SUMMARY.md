## Pagination Pattern Reuse

The implementation explicitly reuses the My Requests URL-driven pagination pattern: server pages parse an allowlisted bounded query, server services pass exact pagination/sort parameters through the typed transport, client navigation uses `router.replace`, page-size changes reset to page 1, and out-of-range pages recover to the last authoritative page. The deliberate presentation difference is that questionnaire inventories remain responsive card grids instead of using the Request DataTable; the shared questionnaire pager therefore renders range, page-size, Previous, and Next controls below the cards.
