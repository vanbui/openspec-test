## Review Fixes

The widened tracking assertion, together with the migrations in 06.6-03 to 06.6-06, surfaced defects that no unit test caught. Each was fixed before commit:

- **Dashboard widget counts** rendered 24px/600 with normal tracking. They now use `text-heading-lg` with tabular numerals, carrying the documented -0.02em.
- **Dashboard recovery links** had been changed to "Open My Requests" for both the error and permission states. The contract is "View My Requests" (`/app/requests`) on error and "Return to sign in" (`/sign-in`) on permission; both are restored.
- **Partial-widget recovery** in the spec still expected the retired "Continue with available dashboard activity" link; it now asserts the shared compact error state.
- **Recovery contract.** The spec encoded a per-route mix from before 06.6. Every list surface now shares one contract through the state primitives — a "Try again" button and a "Return to workspace" link — and the spec asserts that.
- **Card identifier targets** were 15px tall and 19px from the title link, failing WCAG 2.2 target size (2.5.8) on the questionnaire review cards; see the accompanying accessibility commit. The released-assessment card, which this plan also touches, receives the same 24px target here.
