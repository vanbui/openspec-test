<objective>
Create the safe pnpm/Turborepo foundation, copy the existing Strapi source into `apps/strapi` without importing local state or history, and scaffold the `apps/web` workspace contract.

Purpose: establish one reproducible workspace graph without secrets, nested repositories, or mixed lockfiles.
Output: root pnpm/Turbo configuration, reviewed Strapi copy, a web workspace manifest, and documented environment/package verification checkpoint.
</objective>

<threat_model>
## Threat Model

| Threat | Mitigation | Verification |
|---|---|---|
| Secret leakage from sibling Strapi project | Exclude `.env`; preserve only `.env.example`; add explicit ignore rules and inspect staged files. | `git status --ignored` shows `apps/strapi/.env` ignored and `git diff --cached` contains no secret file. |
| Nested Git/history confusion | Exclude `../strapi/.git` and verify `apps/strapi/.git` does not exist. | `Test-Path apps/strapi/.git` is false. |
| Dependency supply-chain/version ambiguity | Stop at a human checkpoint before new dependency installation because registry verification is unavailable. | Approved Node LTS and package versions are recorded before `pnpm install`. |
| CORS/session regression in copied backend | Preserve existing Strapi middleware/plugin configuration for later deliberate review. | Destination contains reviewed `config/middlewares.ts` and `config/plugins.ts`. |
</threat_model>
