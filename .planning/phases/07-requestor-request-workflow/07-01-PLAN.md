<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Next server → Strapi policy | A service credential and server-derived actor assertion cross an HTTP boundary; browser input is untrusted. |
| Strapi policy/controller → IdamBoxUser/Role/Function | Actor identity and analyst elevation are resolved from persisted platform data. |
| Request API → CsrmAssessmentRequest storage | Identifiers, filters, mutable fields, relation IDs, and lifecycle requests cross into persisted records. |

## STRIDE Threat Register — ASVS L1, block threshold high

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-01 | Information disclosure | Request detail/list | high | mitigate | Apply owner/capability filters before lookup and return the same fixed metadata-free response for unknown and non-owned IDs; real HTTP tests compare both. |
| T-07-02 | Tampering / Elevation of privilege | Create/save/transition input | high | mitigate | Whitelist persisted mutable fields; derive requestor, request number, status, and submitted date server-side; test forged bodies and every transition. |
| T-07-03 | Spoofing | Internal caller policy | high | mitigate | Non-public 32-byte-or-longer token, timing-safe digest comparison, server-only actor header, active IdamBoxUser lookup, and policy-before-controller ordering. |
| T-07-04 | Denial of service | List/dashboard queries | medium | mitigate | Allowlisted search/status/sort, bounded page size, bounded dashboard sections, and no arbitrary populate/filter pass-through at the primary trust boundary. |
| T-07-SC | Tampering | Package/dependency surface | high | mitigate | Install no package and require manifest/lockfile no-change. If an unavoidable package change is discovered, halt until a Package Legitimacy Audit and blocking Phase 6 provenance/compatibility approval exist. |
</threat_model>
