## Recorded planning decisions

- **Operation.** `CSRM_ANALYST_INSIGHT_EXPORT_OPERATIONS.exportReport = "POST:/api/v1/reports/{reportKey}/export"`; joins `HUMAN_ANALYST_ONLY_OPERATIONS` and `SERVICE_IDENTITY_REFUSED_OPERATIONS`.
- **Route.** `POST /v1/reports/:reportKey/export` → `api::csrm-analyst-insight.reports.export`, `insightPolicies(exportReport)` extended with `underlyingRead: CSRM_ANALYST_INSIGHT_OPERATIONS.getReport`, `auth: { strategies: ["content-api-token"] }`.
- **Body parser.** `parseReportExportBody(reportKey, body)` in `report-query.ts`: a plain object with only `format` (`csv` | `xlsx`), `table` (string), `timeZone` (string, at most 64) and `query` (an object of at most 16 string values of at most 200 characters); `query` goes to `parseReportRequest(reportKey, query)` unchanged, so an unknown report key is `ReportNotFoundError` (404) and a bad query `ReportQueryError` (400); `table` is checked against the vocabulary's tables for that report by `runFixedTableExport`.
- **Tables (`csrm/exports/report-tables.ts`).** `reportExportTables(request, figures)` returns `ExportTable[]` for the report, one per vocabulary table in order, each row built from the same figures the report read returns (counts as numbers, ratings and statuses as their page labels, system names, dates as dates); no figure is recomputed.
- **About rows.** `As at` (the report's as-at date in the viewer's zone) and, when the report has a period, `Period` (its label as the page shows it).
- **File names.** XLSX `{reportKey}-report-{date}.xlsx`; CSV `{reportKey}-{table slug}-{date}.csv` (19-UI-SPEC §3.2).
- **Specification.** `/v1/reports/{reportKey}/export` (`post`): the `reportKey` path parameter as `GET /v1/reports/{reportKey}` declares it; a closed JSON `requestBody` matching the body parser; the binary 200 and errors as 19-05 declared plus 404.
- **Catalogue (docs copy, then copy over).** New Function `function.reports.export_api` (`Report Export API`, description `Human analyst-only report export grant. This API-only Function intentionally has no menuPath.`, `roleIds: ["role.security_analyst"]`, the report's `sourceEntities`); move `function.reports.reports.api.03` to `function.reports.export_api.api.01` with name, URL and description unchanged; `function.reports.reports.functionApiIds` becomes empty. The Phase 19 design note (19-05) already names the Function.
- **Tests that pin the reserved entry.** `contract-catalogue.integration.test.ts` replaces `PHASE7_REPORT_EXPORT_PUBLISHED`'s "unpublished" assertion with one that the path is published and served by `function.reports.export_api`; `analyst-insight-catalogue-seed.integration.test.ts` expects the Reports menu Function with no FunctionApis; `served-operations.integration.test.ts` drops the deferred reason for `POST:/api/v1/reports/{reportKey}/export`; `analyst-insight-routes.unit.test.ts` adds `/v1/reports/:reportKey/export` to its served-export allow-list.
