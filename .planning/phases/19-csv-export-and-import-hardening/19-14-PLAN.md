## Recorded planning decisions

- **Operations (in `CSRM_ADMINISTRATION_OPERATIONS`).** For each collection segment `risk_types`, `controls`, `information_systems`, `information_assets`: `export<Plural>` = `GET:/api/v1/{segment}/export`, `download<Plural>ImportTemplate` = `GET:/api/v1/{segment}/import/template`, `download<Plural>ImportErrorReport` = `POST:/api/v1/{segment}/import/error_report`. The four exports join `HUMAN_ANALYST_ONLY_OPERATIONS` and `SERVICE_IDENTITY_REFUSED_OPERATIONS`.
- **Routes (in `routes/csrm-administration.ts`, before each collection's `/:id` routes).** Templates and error reports use the file's `policies(operation)` (`requireAnalystAdministrationScope: true`); exports use the same plus `underlyingRead` set to the collection's `list…` operation. All `auth: { strategies: ["content-api-token"] }`.
- **Template (`buildImportTemplate(kind, format)`).** Headers are the vocabulary's import labels in contract order; one example row: the natural key `Example (CSRM skips this row)` (`EXAMPLE` for controls), every other column a plausible value (the first allowed value for enumerations, `Yes` for flags, `Example description` for text); text columns `@`; XLSX sheets `{plural} import` then `Notes` with columns `Column`, `Also accepted as`, `Required`, `Format and allowed values`, `A blank cell`, an empty row, and the six §3.4 rules (`{singular}` filled per collection). File name `{collection slug}-import-template.{csv|xlsx}`. No dropdowns.
- **Error report (`buildImportErrorReport({ kind, actorDocumentId, upload, previewDigest?, resultToken?, timeZone? })`).** Exactly one token, else 400. The record must exist for this actor and collection (else 409 `IMPORT_REVIEW_EXPIRED`) and its `fileDigest` must equal the upload's (else 400). The rows come from `readImportFile` of the upload; the header row is written as typed; a row is included when, at Review, its retained state is `rejected`, `ambiguous` or `similar`, and at Results, when its outcome is not imported and not the person's own skip (rejected, ambiguous, drifted); cells are written verbatim through the writer's neutraliser; the last column is `Issues`, each message `Row {original row number}: {message}` joined by `; `, messages regenerated from the retained codes through the import's closed issue vocabulary with column labels, and a similar row's message the S4 sentence `Matches the existing name “{existing name}” except for capitals or spacing. Type the existing name exactly to update it.`. Format follows the upload; CSV carries the BOM. File name `{collection slug}-import-issues-{local date}.{ext}`; `X-CSRM-Row-Count` holds the report's row count. No export event (D-32).
- **Reference views (`referenceListExportView(kind)`).** The admin list's own query parser with an export variant `parseAdministrationExportQuery(kind, query)` beside `parseAdministrationQuery`'s server twin, refusing `page` and `pageSize`; the admin repository's count, ordered ids and hydration; extractors for the import columns (stored values, flags `Yes`/`No`) and the read-only columns (`owner` display name, `applicableControls` count). The file's header labels equal the template's, so the file imports back.
- **Specification.** Twelve paths: the exports as 19-05's binary shape with the admin list's query parameters; templates with `format` (required, `csv` | `xlsx`) and a binary 200 without `X-CSRM-Row-Count`; error reports with a multipart body (`file`, `previewDigest`, `resultToken`, `timeZone`) and a binary 200 with `X-CSRM-Row-Count`; errors 400, 401, 403, 409 and the file refusals from 19-13.
- **Catalogue (docs copy, then copy over).** Each of `function.administration.risk_types`, `.controls`, `.information_systems`, `.information_assets` gains three FunctionApis with its next free numbers (expected `.api.05` to `.api.07`): `Export {Plural}` (`Exports the {plural} list in the requested supported format, with its import columns.`), `Download {Plural} Import Template` (`Generates the {plural} import template in the requested supported format.`), `Download {Plural} Import Error Report` (`Rebuilds the rows of an uploaded {plural} file that were not imported, with their issues.`).
