This plan's slice: the Admin retires Risk Types and names asset owners in the reference screens, and analysts see retired and off-list values marked wherever they choose or filter.

## Recorded planning decisions

- **Workspace.** `AdministrationWorkspace` (Risk Types): `SegmentedControl` `Show` with `Active ({n})` and `Retired ({n})` from `meta.statusCounts`, kept in the address as `?show=retired`; with `canManage`, each active row ends with a ghost small `Retire` (name `Retire {name}`) and retired rows with outline small `Reinstate` (`ArchiveRestore`), each optimistic with rollback, moving focus to the next row and toasting UI-SPEC §4.2's sentences with Undo calling the inverse; details gain `Retire Risk Type` or `Reinstate Risk Type` and `History` (opening `ChangeHistorySheet` for the record) for the Admin only (the analyst's History is withheld: D-12 keeps change rows Admin-only, recorded at 22-01's checkpoint); `UsagePanel` gains `plain` (no links, `Used in` rows plain with `Security Analysts open these lists.`), set when `canManage`.
- **Assets.** `AdministrationForm` (assets) gains `Owner` with `OwnerCombobox`, hint `The person accountable for this asset.`, seeding `Selected owner: {name}`; the list's columns become `Name`, `Owner`, `Classification`, then today's; phone cards add `Owner: {name} · Classification: {value}`; fallbacks `Not provided` and `{name} (inactive)`.
- **Options (`list-options.ts`, zod-free).** `retiredLabel(name)` → `{name} (retired)`; `riskTypeChoiceLabel(storedName, activeNames)`; `listFilterOptions(lists, recordedValues)` → active entries in order, retired ones suffixed, then a `Not on the list` group of recorded values matching no entry by label key.
- **Filters.** `ListValueFilter` loads the lists through `loadRequestListsAction` (a `'use server'` action over `getRequestFormMetadata`) and the off-list values through the existing suggestions action; `risk-register-filters.tsx` and `report-filters.tsx` render it for `Division` and `Business unit`, and their Risk Type option lists order active types first, then retired ones with the suffix (from `isActive`).
- **Risk editors.** The Risk Type select in `risk-editor.tsx` and the table's picker cell editor offer the active picker list only and render a stored type absent from it as `riskTypeChoiceLabel(...)`.
- **Copy.** Family AA3's reference rows per UI-SPEC §12.
