## Recorded planning decisions

- **`risk-scale.ts`.** `riskBands()` = `storedSettingValue("risk-scale")?.bands ?? DEFAULT_RISK_BANDS` (`{ lowMax: 4, moderateMax: 9, highMax: 16 }`, exported); `deriveRating(likelihood, consequence, bands = riskBands())`; `publishedRiskScale()` takes descriptions and bands from the stored setting or the defaults (18's shape unchanged); `RiskAppetiteEntry` gains `treatmentExpected: boolean` (defaults per 22-01); `riskAppetite()` = the stored bands or `DEFAULT_RISK_APPETITE`; `treatmentExpected(rating, appetite = riskAppetite())`; `acceptProposalAllowed(rating, appetite = riskAppetite())` true only for Low or Moderate whose entry is `risk-owner` with `treatmentExpected: false`. Every function that takes `appetite` keeps it as an optional last argument.
- **`review-policy.ts`.** `reviewPolicy()` = the stored value or `DEFAULT_REVIEW_POLICY`.
- **`data-policy.ts`.** `aiDataPolicy({ deploymentCeiling, development })` returns `{ ceiling, unclassifiedDefault, source }`: a stored setting wins (`source: "setting"`); otherwise `parseClassificationCeiling(deploymentCeiling)` (`deployment` when set, `none` when not) with `unclassifiedDefault: "Internal"`. `readAiDataPolicyConfiguration` and `requestClassification(assets, unclassifiedDefault)` take the result, so every refusal path (12 D-28's enqueue and run checks, Phase 14's inclusion refusal) reads the same decision. `aiPolicySourceNotice(stored, deploymentCeiling)` returns `CSRM AI data policy: the Admin's recorded ceiling {stored} applies; CSRM_AI_DATA_CLASSIFICATION_CEILING ({env}) is ignored.` when both are set and differ, else null; `loadConfigurationStore` logs it once at `info`.
- **Prompts.** The draft (and questionnaire, where 12 gives it the scale) system instructions gain a `Rating scale` section built from `publishedRiskScale()`: labels, scores, the four band ranges and each description (already bounded to 300 characters by the setting), placed with the other trusted instructions and never inside the untrusted data block.
- **Retention.** `attachmentRetentionYears()` = `storedSettingValue("record-retention")?.years ?? ATTACHMENT_RETENTION_YEARS_AFTER_CLOSURE`; `RequestAttachmentListMeta` gains required `retentionYears` (integer); the web parser in `attachments-schema.ts` reads it.
- **`.env.example`.** The `CSRM_AI_DATA_CLASSIFICATION_CEILING` comment says it bootstraps the ceiling until the Admin records one in Configuration, after which it is ignored; the value stays empty.
