## Recorded planning decisions

- **Usage reads.** `GET /v1/information_systems/:informationSystemId/usage` → `{ data: { requests: n, openRisksByResidualRating: { critical, high, moderate, low, notRated }, underAssessment: n } }` where `requests` counts non-draft requests naming the system through the queue's `queue=all` population and `informationSystem` filter, and the risk figures count risks whose `informationSystemImpacted` is the system through the register's predicates (`stage=released&state=open&system={id}&residualRating=…`; under assessment as 11's separate branch); assets use `informationAsset` and the register's `asset`. `GET /v1/controls/:controlId/usage` → `{ data: { controlImplementationsByStatus: { existing, planned, implemented, retired }, openRisksHoldingControl: n } }`. `GET /v1/risk_types/:riskTypeId/usage` → `{ data: { openRisksByResidualRating, underAssessment } }`. A missing record → 404. The UI-SPEC's link parameter `impactedSystem` maps to the register's existing `system` (and `asset`) parameters (recorded difference).
- **List counts.** `usageCountsFor(kind, documentIds)` in one grouped query per list page; list rows gain `usage: { requests?: n, openRisks: n }` (requests for systems and assets only).
- **Suggestions.** `parseRequestFieldSuggestionsQuery`: exactly `field` (`division` | `businessUnit`) and `q` (1–100), else 400. Distinct `TRIM` values whose lower case contains `q`'s lower case, the first-seen casing kept per case-folded value, ordered alphabetically, `REQUEST_FIELD_SUGGESTIONS_MAX = 8`; drafts included only for the caller's own requests; for a caller who is not a human analyst, only requests whose `requestor` is the caller.
- **Routes.** In `routes/csrm-administration.ts`: the four usage routes (analyst administration scope) and `GET /v1/request_field_suggestions` (its own handler, `listRequestFieldSuggestions`, without the administration scope check; the policy and the record rule decide).
- **Catalogue.** `.api.03` `Get Information System Usage`, `Get Information Asset Usage`, `Get Control Usage`, `Get Risk Type Usage` on `function.administration.information_system_details`, `information_asset_details`, `control_details`, `risk_type_details`; `function.risk_assessment_requests.field_suggestions_api` (`Request Field Suggestions API`; `role.requestor`, `role.security_analyst`; `.api.01` `List Request Field Suggestions`). The four usage literals join `HUMAN_ANALYST_ONLY_OPERATIONS` and its matrix mirror; all five join `SERVICE_IDENTITY_REFUSED_OPERATIONS`.
- **Contract.** Spec tags `administration` and `assessment-requests`; components `InformationSystemUsage`, `InformationAssetUsage`, `ControlUsage`, `RiskTypeUsage` with their responses, `ReferenceUsageCounts` on the list rows, `RequestFieldSuggestionsResponse` (`{ data: string[] }`); `administration-schema.ts` parses the list rows' `usage` and the four usage responses.
