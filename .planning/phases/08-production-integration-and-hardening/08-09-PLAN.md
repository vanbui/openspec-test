## Recorded planning decisions

- **`global-error.tsx` shares the font setup through `app/fonts.ts`:** the three `next/font/google` declarations move out of `app/layout.tsx` into `app/fonts.ts` exporting `fontVariableClassName`, and both the root layout and the global error import it, because a global error UI replaces the root layout and must load `globals.css` and the fonts itself (`error.md` "Global Error"). `metadata` is not supported there, so the title is a React `<title>` element.
- **`retry` over `reset`** for the new boundaries (stable in Next 16.3; the analyst dashboard boundary already uses it). Existing segment boundaries keep `reset`; the inventory test only forbids reading `error.message`, `error.digest` and `error.stack`.
- **Print hides by selector where one exists and by marker where none does:** `form[role="search"]` covers every search form; the seven list filter containers (search plus status/queue selects), the `PageHeader` action slot, the DataTable density toggle, chip remove buttons, `Clear filters`, and the footer's `Rows per page` and page buttons get `data-print="hidden"`; the `{n} results` and `Page {x} of {y}` outputs and the chip labels stay printable (UI-SPEC §8).
- **The print proof runs at a 794px viewport with `page.emulateMedia({ media: 'print' })`** on the Risk Register, the risk-exposure report and a Risk detail, inside `design-system-conformance.spec.ts` (it already owns the cross-route conformance matrix); `emulateMedia({ media: null })` restores screen media afterwards.
- **X-4 is recorded as the first step of Task 1 (plan check, 2026-09-25):** D-45 asks for each extension to be recorded as the first task of the plan that first implements it, so the `### Print` subsection and its `docs(08-09): …` commit precede the trigger rename, not the stylesheet task.
- **File count accepted under D-49 (plan check, 2026-09-25):** the plan lists 27 files, above the 15-file guideline, because its edits are mechanical multi-site changes of one kind (the fourteen renamed trigger sites, the nine `data-print` marker sites, and the root fallbacks) and the executor runs with a large context; it is not split, and the three tasks keep disjoint file sets.
