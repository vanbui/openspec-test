| Decision | How this plan honours it |

| D-05 | For each Phase 7 bound (research §F1.6 table) the contract declares the bound the server guarantees (preferred), `.trim()` is dropped from machine identifiers so parser and contract coincide, and any remaining deliberate narrowing goes into `narrowedPaths` with a reason. |
| D-40 | The guard's boundary mode fails on any unregistered narrowing in the Phase 7 parsers and in every parser this phase adds or changes; older parsers are grandfathered through one explicit allow-list entry each with a reason, and the count is recorded for VERIFICATION as a backlog. |

## Recorded planning decisions

- **Boundary mode is two payloads per parser:** `boundary-empty` (every string without `minLength` is `''`; every string with `minLength` is exactly that long; numbers and everything else as in `minimal`) and `boundary-long` (every string without `maxLength` is 70,000 characters, longer than any client cap, the largest of which is `max(65_535)`; every string with `maxLength` is exactly that long; patterns and enums keep their existing synthesis). A parser that rejects either payload must have the bound declared in the spec or the path in `narrowedPaths`.
- **Scope of the grandfather list (Open Question 7):** every parser registered before Phase 8 except the eight Phase 7 registrations (`alerts.listAlerts`, `alerts.getAlertSummary`, `analystDashboard.getDashboardSummary`, `reports.listReportDefinitions`, the four `reports.getReport.*` branches) may appear in `boundaryGrandfathered` with a reason such as "client-declared bounds predate Phase 8; the contract bound for this family is a backlog item". The test fails if a grandfathered label no longer rejects a boundary payload (a stale entry) or if a non-grandfathered parser rejects one without a `narrowedPaths` entry. The list length is asserted and recorded.
- **`.trim()` is removed only from machine identifiers** (documentIds, record numbers, alert ids) in the three Phase 7 modules; a `trim()` on free text elsewhere is a grandfathered narrowing, not changed here.
