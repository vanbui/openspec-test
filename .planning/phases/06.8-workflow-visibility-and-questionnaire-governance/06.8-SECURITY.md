# Phase 06.8 — Security

> Per-phase security contract: threat register, accepted risks, and audit trail.

## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| Browser to Next.js and Strapi | Actor-controlled identifiers and mutation bodies enter typed application boundaries. | Request, questionnaire, and assessment data |
| Strapi to SQLite | Workflow state and JSON envelopes re-enter as untrusted persisted data. | Release facts, definitions, answers, audit events |
| Strapi to browser | Server projections decide record visibility and available navigation. | Actor-scoped workflow projections |
