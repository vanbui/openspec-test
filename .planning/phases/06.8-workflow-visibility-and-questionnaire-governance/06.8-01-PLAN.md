<objective>
**As a** Security Analyst, **I want to** keep an AI-generated questionnaire private until I explicitly release it to its Requestor, **so that** a Requestor never answers questions I have not reviewed and every release is recorded as an auditable fact.

This plan is the spine of Phase 06.8. It adds the three pre-approved `CsrmQuestionnaire`
attributes, the append-only governance log module, the first protected governance operation
(release), and the server-authoritative release gate. It also publishes the complete Phase 06.8
contract, catalogue, and typed-client surface once, so that no later plan in this phase has to
touch `docs/references/specification.json`, either catalogue copy, or the generated client again.

Purpose: criteria 3, 4 and 8 all rest on a persisted, server-owned release fact that the
authorization layer reads directly (D-05, D-14). Nothing else in the phase can be built until it
exists.
Output: three new schema attributes, two new Strapi service modules, one mounted release
operation, five published operations, two new Strapi test files, and realigned development
fixtures.
</objective>

Add the three approved optional attributes to the `CsrmQuestionnaire` schema, exactly as
`docs/contract-gaps/phase-06.8-questionnaire-governance-facts.md` specifies and nothing more:

Create `questionnaire-governance-log.ts` as pure functions with no Strapi dependency. Export a
frozen `GOVERNANCE_EVENT_KINDS` tuple of exactly `released`, `returned-to-review`,
`question-added`, `question-edited`, `question-deleted`, `answer-cleared`. Export `GovernanceLogError`.
Export `parseGovernanceLog(value)` which accepts `null`, `undefined` and `[]` as an empty log and
otherwise requires an array of at most 1000 entries, each an object whose keys are exactly
`schemaVersion`, `kind`, `at`, `by`, and the optional `reason`, `questionKey` and `explanation`;
`schemaVersion` must equal 1, `kind` must be in the tuple, `at` must be a parseable ISO instant,
`by` must be a non-empty string of at most 255 characters, `reason` at most 500 characters,
`questionKey` at most 120 characters, `explanation` at most 500 characters. Reject anything else by
throwing `GovernanceLogError`; the read path treats that as an empty log so a malformed array fails
safe rather than denying the record. Export `appendGovernanceEvent(existing, event)` which parses
`existing`, validates the new event through the same parser, and returns a new array with the event
appended last. `appendGovernanceEvent` is the only writer: it must never remove, reorder or rewrite
a prior entry, and there must be no exported function that can.

Create `questionnaire-governance-workflow.ts` reusing the transaction shape of
`questionnaire-workflow.ts`: a per-`documentId` promise-tail mutation queue, a `db.transaction`, and
a `queryBuilder(...).forUpdate()` row lock on `api::csrm-questionnaire.csrm-questionnaire` taken
before any read. Export `QuestionnaireGovernanceError` carrying a 400, 403, 404 or 409 status.
Export `assertAnalystGovernanceActor(input)` which throws 403 unless `actor` is `analyst` and
`actorDocumentId` is a non-empty string. Export `releaseQuestionnaire(input)` which, inside the
locked transaction, reloads the questionnaire with its `assessmentRequest` populated, refuses with
409 when `releasedAt` is already set, when the owning request status is neither `submitted` nor
`questionnaire-in-progress`, when the request already has a linked assessment, or when the
questionnaire has no parseable question definition; and otherwise performs one `documents(...).update`
that writes `releasedAt` from the server clock, `releasedBy` from `actorDocumentId`, and the
`governanceLog` value returned by `appendGovernanceEvent` for a `released` event. Release takes no
request body: reject any non-empty body with 400, because D-16 scopes the mandatory reason to the
three standalone backward transitions and release is not one of them.

Add `release: "POST:/api/v1/questionnaires/{questionnaireId}/release"` to

controller handler that resolves the questionnaire id and the acting identity, calls
