## Phase Goal

**As a** Security Analyst, **I want to** pick up a request and exchange notes with the Requestor on it, **so that** ownership is clear and new information has a home at any point.

This plan's slice: the Requestor and the Security Analysts can add and read notes on a submitted request through Strapi and the web's typed layer, each person's unread notes are counted from the server, and nobody else can reach them.

<objective>
Create the two approved content types (D-01 item 2) and serve `GET` and `POST /api/v1/assessment_requests/{requestId}/notes` and `POST …/notes/read` with the window, the readers, the unread rule, the bounds and the posting-time AI-input mark (D-21 to D-24, D-26), their grants, contract, matrix rows and closed reasons (D-02, D-30), and the web's typed service, Server Actions and refusal family L.

Purpose: COLLAB-01 criteria 1, 2 and 4 at the API; UAT-013.
Output: two content types with no core route, three operations end to end to Server Actions.

Edits Strapi source? Yes. Changes the specification? Yes. Runs Playwright? No. Regenerates `served-operations.json`? Yes.
</objective>

## Recorded planning decisions

- **Folder.** `apps/backend/src/api/csrm-request-note/` holds both content types (`content-types/csrm-request-note/schema.json`, `content-types/csrm-request-note-read-state/schema.json`), `services/`, `controllers/request-notes.ts`, `routes/request-notes.ts` (the standalone router shape of `my-request-status-summary.ts`) and `operations.ts`. - **AI-input log** `note-ai-input-log.ts`: `NOTE_AI_INPUT_LOG_SCHEMA_VERSION = 1`, `NOTE_AI_INPUT_LOG_MAX_EVENTS = 200`, events `{ schemaVersion, by, at, from: boolean, to: boolean }`, `parseNoteAiInputLog`, `appendNoteAiInputEvent` (the 06.8 posture). A posting-time mark writes one event `{ from: false, to: true }` by the author at `postedAt`.
- **Service** `request-notes.ts`: `listRequestNotes({ strapi, requestDocumentId, caller, before?, limit? })` (no lock; one read of the page by `sequence` descending then returned ascending; `meta`: `total`, `unread`, `lastReadSequence`, `hasEarlier`, `accepting`, `closedReason`, `viewerPart`, `canMarkAiInputs`); `addRequestNote(...)` and `markRequestNotesRead(...)` under `withRequestLock`, with every count and max-sequence read through `strapi.db.query` or the Document Service so it joins the transaction. `canMarkAiInputs` = the caller is a human analyst, is not the requestor, and the request accepts notes. A note projects as `{ documentId, sequence, body, authorPart, author: Person | null, postedAt, unread, changesAiInputs? }`; `changesAiInputs` is present only when the caller is a human analyst.
- **Controller** `request-notes.ts`: `list`, `create`, `markRead`. Each loads the request (`requestor`, `requestStatus`, `revertedAt`); a missing request or `canUseRequestNotes` false → 404 with one actor-neutral message (`CSRM request notes were not found.`). Query keys for `list`: `before` (integer ≥ 1) and `limit` (1 to 50) only. Create body `{ data: { body, changesAiInputs?: boolean } }` exact keys; `changesAiInputs` from a caller whose part is `requestor` and who is not a human analyst → 400; from a requesting analyst → 403 `OWN_REQUEST`. Read body `{ data: { throughNoteId } }`; a note not on this request → 404.
- **Operations** `operations.ts`: `CSRM_REQUEST_NOTE_OPERATIONS = { list: "GET:/api/v1/assessment_requests/{requestId}/notes", create: "POST:/api/v1/assessment_requests/{requestId}/notes", markRead: "POST:/api/v1/assessment_requests/{requestId}/notes/read" }` (13-06 adds `setAiInput`).
