## Phase Goal

**As a** Security Analyst, **I want to** pick up a request and exchange notes with the Requestor on it, **so that** ownership is clear and new information has a home at any point.

This plan's slice: the Requestor sees, on Home, My requests and the request's next step, which Security Analyst holds each request or that it waits for one, and which requests have new notes for them.

<objective>
Name the assignee in the Requestor-facing holder sentences (D-17), add the assignee name, the unread count and the notes filter to My requests and the unread total to the status summary (D-17, D-24), and show them on My requests and the Requestor Home (UI-SPEC §12); change the existing journeys that assert the old sentence deliberately.

Purpose: success criteria 1 (Jane's surfaces) and 4 (the reply flagged for the Requestor); REQ-08 criterion 1; COLLAB-01 criterion 2's Requestor Home flag.
Output: two read changes, the sentences, two surfaces, journey changes.

Edits Strapi source? Yes. Changes the specification? Yes. Runs Playwright? Yes. Regenerates `served-operations.json`? No.
</objective>
