## Recorded planning decisions

- **Risk schema.** Add, in this order after `treatmentStatus`: `withdrawnAt` (`"type": "datetime"`), `withdrawnBy` (`"type": "relation", "relation": "manyToOne", "target": "api::idambox-user.idambox-user"`, no `inversedBy`, copying `riskOwner`'s form) and `withdrawalReason` (`"type": "text"`). No other attribute changes.
- **History type folder.** `csrm-risk-history-event` copies `csrm-risk-type`'s folder: `factories.createCoreService`, `factories.createCoreController`, `factories.createCoreRouter(..., { only: [] })`. Schema: `"kind": "collectionType"`, `"collectionName": "csrm_risk_history_events"`, info `singularName` `csrm-risk-history-event`, `pluralName` `csrm-risk-history-events`, `displayName` `CSRM Risk History Event`, `"draftAndPublish": false`, and the attributes the record fixes (`kind` string required maxLength 64; `occurredAt` datetime required; `actor`, `assessment`, `risk`, `aiRun` unidirectional manyToOne to `api::idambox-user.idambox-user`, `api::csrm-assessment.csrm-assessment`, `api::csrm-risk.csrm-risk`, `api::csrm-ai-run.csrm-ai-run`; `sourceKind` string required maxLength 32; `proposalItem` and `batchId` string maxLength 64; `reason` text; `undo` boolean default false; `changes` json).
- **Writer.** `recordRiskHistory(strapi, entry)` validates the entry (kind in `RISK_HISTORY_KINDS`; source in `RISK_HISTORY_SOURCES`; `aiRunDocumentId` required exactly when the source is `ai-run`; reason required for `withdrawn` and `reinstated`, at most 500; changes through `buildRiskHistoryChanges`), then calls `strapi.documents("api::csrm-risk-history-event.csrm-risk-history-event").create` without opening its own transaction, so it joins the caller's `strapi.db.transaction` (the pattern of `withMutableAssessmentMutation`). It throws `RiskHistoryError` on an invalid entry, never writes partially, and is the only module that creates rows. The module exports no update or delete.
- **Read.** `readRiskHistory(strapi, { riskDocumentId, page, pageSize })`: `RISK_HISTORY_PAGE_SIZE` 25, `RISK_HISTORY_PAGE_SIZE_MAX` 100 (a larger or non-integer value is a 400 at the caller); sort `occurredAt:desc` then `id:desc`; returns `{ events, pagination: { page, pageSize, pageCount, total }, recordedFrom }` where each event projects `id` (documentId), `kind`, `occurredAt`, `actor` (`{ documentId, displayName }` or null from one batched people read), `sourceKind`, `aiRunId`, `proposalItem`, `reason`, `undo`, `changes` (parsed, or null when malformed; the malformed row is logged once per read, the 06.8 posture). `recordedFrom` is the earliest `occurredAt` for the risk, or null.
- **Undo source.** `latestWithdrawalReason(strapi, riskDocumentId)` returns the reason of the risk's most recent `withdrawn` row, or null. It is the only history read on a write path and decides no access (D-18: gates never read history).
- **Reasons.** Append the four codes to `CONFLICT_REASONS` in both lists and to the `reason` enum of both conflict response schemas (`AssessmentWorkflowErrorResponse` and the other schema 10-06 extended); each list's comment names Phase 16.
