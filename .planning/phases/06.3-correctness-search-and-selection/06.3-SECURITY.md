# Phase 06.3 — Security

> L1 verification of the threat models in all Phase 06.3 plans against their completed summaries, the completed UAT, and the validated automated-test map.

## Trust Boundaries

| Boundary | Description | Data Crossing |
|---|---|---|
| Browser query state to typed services | Untrusted search, filters, pages, and selected identifiers are parsed before use. | Query strings and identifiers |
| Typed services to Strapi | Only typed, bounded operations enter the production authorization boundary. | Authorised request data |
| Strapi policy to repository query | Owner/review scope is server-derived and combined with bounded predicates. | Scoped records |
| Strapi response to client UI | Closed parsers and bounded projections prevent raw entity disclosure. | Public DTOs |
