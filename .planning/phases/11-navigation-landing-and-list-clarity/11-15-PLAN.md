## Recorded planning decisions

- **The shared rule.** `TREATMENT_DUE_DATE_COLUMN = "r.target_date"` and `applyTreatmentDueStatePredicate(query, state, { today, windowDays = ALERT_DUE_SOON_WINDOW_DAYS })` (outer query aliases `csrm_risks` as `r`): `complete-or-closed` → `(r.closure_date IS NOT NULL OR r.treatment_status = 'Complete')`; every other state starts from the open condition `r.closure_date IS NULL AND (r.treatment_status IS NULL OR r.treatment_status <> 'Complete')` and adds `date IS NULL` (no-target-date), `date < today` (overdue), `date >= today AND date <= today + window` (due-soon) or `date > today + window` (later), with `today` and the window end bound as `YYYY-MM-DD` strings, as `deriveTreatmentDueState` compares them. The code comment above both functions reads: "Phase 20 (G-16) switches this rule's governing date from targetDate to treatmentResolveDate (falling back to targetDate for a treated Risk without one). Every due or overdue figure reads it here: deriveTreatmentDueState for one Risk, applyTreatmentDueStatePredicate for a list or a count."
- **None and any.** Rating `none` → `(col IS NULL OR col NOT IN ('Low','Moderate','High','Critical'))` (research Pitfall 11); treatment status `none` → `(r.treatment_status IS NULL OR r.treatment_status NOT IN ('Not Started','In Progress','Overdue','Complete'))`, matching the report's `notProvided`; `mitigationStatus=any` → an implementation exists; `mitigationEffectiveness={value}` → an implementation with that `effectiveness_rating` exists, `none` → one with a null or off-vocabulary rating exists; `impactedSystem=none` → no `csrm_risks_information_system_impacted_lnk` row. `impactedSystem` with `system` is a 400.
- **Labels (UI-SPEC §9.5).** Due state options `All`, `Overdue`, `Due soon`, `Due later`, `No target date`, `Complete or closed`; effectiveness `All`, `Effective`, `Partially Effective`, `Ineffective`, `Not Assessed`, `Not provided`; status adds `Any mitigation control`; `Not rated` and `Not provided` options; chips `Due state: Due later`, `Mitigation-control effectiveness: Effective`, `Mitigation-control status: Any mitigation control`, `Impacted system: None`.
- **Alerts and reports** keep their own population this phase (D-43); plan 11-17 moves the report's due-state counts and the alert treatment kinds onto this rule.
