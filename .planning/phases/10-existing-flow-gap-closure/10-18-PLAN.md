## Phase Goal

**As a** Security Analyst or Requestor, **I want to** have the existing request, questionnaire, assessment and administration screens work as they say, **so that** today's flow completes without workarounds, lost input or misleading messages.

This plan's slice: an analyst adds a mitigation control by typing its number or name, with the controls that apply to the Risk's type offered first, instead of scrolling a 2,646-option list.

## Recorded planning decisions

- **Picker file and name.** `apps/csrm/src/components/csrm/relation-picker.tsx` exports `RelationPicker` (PATTERNS.md). Items are `{ documentId, name, detail? }`, which matches `RelationSelection`, so the request selector actions plug in directly in plan 10-19.
- **Control search page size:** 10 (Planner's Discretion "the picker page size, within the existing selector bounds"; the Administration sizes are 10, 25, 50 and 100). A full page shows `Showing the first 10 matches. Keep typing to narrow the list.`
- **Applicable-control schema:** a new closed component `RiskTypeApplicableControl` (`documentId`, `controlNumber`, `name`, `framework`, each a string of 1-255, the Controls Administration record's bounds), required on `RiskTypeSummary` as an array with `maxItems: 1000`. Populated sorted by control number.
- **The Risk Register's picker parser** (`risk-schema.ts`, `listRiskRegisterRiskTypes`) reads the same `RiskTypeListResponse` and is closed, so it accepts the same field; it has no runtime caller today, but the parity guard checks it.
- **Search failure copy** reuses the request selector wording (`request-actions.ts`): 403 `You do not have permission to search these records.`, otherwise `The selection service is unavailable. Please try again later.`
- **Selected control without a summary** reads `Control not found`, never an id (UI-SPEC §16.2's rule, applied to the editor).
- **Required message.** `selectRelationMessage` becomes `chooseRelationMessage` and the control message reads `Choose a control.` (UI-SPEC §13.1); it is the only caller.
- **Focus on open (UI-SPEC §13.1).** `Add mitigation control` moves focus to the new form's `Control` input in the assessment editor too.
