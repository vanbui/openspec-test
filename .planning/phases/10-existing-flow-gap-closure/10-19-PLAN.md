## Recorded planning decisions

- **Selected labels in the assessment editor** come from the risk list read plan 10-15 made (`listAssessmentRisks`, whose items carry `informationSystemImpacted` and `informationAssetImpacted` as `{ documentId, name }`). The review page now reads it for every assessment, not only a released one, and passes a label map. This is D-30's "served relation"; the Requestor-granted hydrate routes are not used for analyst screens.
- **An id with no served name** (a record removed since) reads `Name not available`, the wording UI-SPEC §16.4 uses for an owner without a name; never an id.
- **Assessment editor reads:** a 403 from the request or risk list read shows the permission state and any other failure the error state, as the removed inventory reads did.
- **Risk Register reads (research Open Question 2):** only for a mutable Risk, read the analyst assessment and then its request; any failure leaves the suggested groups empty and the editor searches only. The Risk's own `informationSystemImpacted` and `informationAssetImpacted` label the selection.
- **Search sources:** `searchInformationSystemsAction` and `searchInformationAssetsAction` (`request-actions.ts:69-75`, a 25-row page, so a full page reads `Showing the first 25 matches. Keep typing to narrow the list.`); controls use `searchControlsAction` (plan 10-18).
- **Search functions travel in props** (`RiskDetailsOptions.searchControls`, `searchSystems`, `searchAssets`; `AssessmentEditor` props `searchSystems`, `searchAssets`), so `risk-details.tsx` is untouched here and tests pass fakes.
- **After a mitigation create or update**, the card's control comes from the response's `controlSummary` (plan 10-15), else the current control; if neither exists the form shows `The selected control is no longer available. Choose another control.` (§13.5).
- **The new browser proof** imports 26 uniquely named Information Systems through the Administration CSV import (its own fixture, D-39), then finds the 26th by typing in the Risk Register editor and discards the edit, so the shared mutable Risk is unchanged.
