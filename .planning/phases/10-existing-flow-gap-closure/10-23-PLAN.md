## Recorded planning decisions

- **Task 1 is `auto`, not a tracer.** A gate has no slice to trace, and a tracer's feedback gate would rerun this roughly 30-minute verify before the next task (plan check Warning 3).
- **The `CSRM_AI_` check is scoped to source.** It diffs `apps`, `scripts` and the root `package.json`, `turbo.json` and `pnpm-workspace.yaml`. The planning documents committed after `5ea2b77` name the variables in their rules (the unscoped diff printed 45 matching lines on 2026-09-28, every one under `.planning/`), so an unscoped check could never pass on a correct tree.
- **Commit, then check the tree.** Task 1 commits the gate record before its clean-tree check, and Task 3 commits the walk record before its own. A clean-tree result is never written into the summary after that summary's commit, because writing it would dirty the tree again; the task's verify output is the evidence.
- **The walk is the orchestrator's (Task 2).** It needs the dev servers restarted on the phase's code, which only the orchestrator may do, and it is a `gate="blocking-human"` checkpoint so no mode can auto-approve it. Task 3's verify fails while any backstop row is missing, pending or an issue, so the plan cannot pass on a summary that says the walk is still to come.
- **Browser checks change no operator data.** The walk navigates, opens pickers and lists, types searches, opens dialogs and cancels them, and presses Save only on unchanged forms (the `No changes to save.` note occupies the same place as a save confirmation, so its layout proves the backstop without writing). It never types questionnaire answers (autosave would write) and never presses Generate, Replace, Retry, Submit, Release or Confirm import.
- **No live AI generation** runs against the dev Strapi: its provider is a hosted API.
- **ADMIN-05 is partial by decision.** Its criterion 1 names asset owners, and `CsrmInformationAsset` has no owner: that needs a content-type change, so it moves to Phase 22 with a contract-gap record (D-01, D-37, REQUIREMENTS.md ADMIN-05 Remainder, ROADMAP Phase 22 "Carried from Phase 10"). Everything else in ADMIN-05 is delivered here: system owners by name and the list columns (plan 10-16), complete Privacy Principle titles and Risk Type descriptions (plan 10-17), the label rule (plan 10-15), and titles for every seeded control (plan 10-22, D-46).
