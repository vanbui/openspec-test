## Phase Goal

**As a** Security Analyst or Requestor, **I want to** have the existing request, questionnaire, assessment and administration screens work as they say, **so that** today's flow completes without workarounds, lost input or misleading messages.

This plan's slice: an analyst who replaces a questionnaire sees exactly what the replacement will discard before confirming, and is never offered a replacement the server refuses.

<objective>
Build the hub side of UAT-019 on plan 10-11's contract: `Replace questionnaire` with a confirmation that states the discard count (D-08), no offer and an explanatory hint while the questionnaire is released (D-09), and the failure copy by code (UI-SPEC §12.4). The analyst request page reads the questionnaire summary for the count.

Purpose: UAT-019 (QUES-08 criterion 3) and the analyst-hub part of UAT-036.
Output: the zod-free action predicate, the rebuilt replace flow and its unit tests, the page read, and journey change E7 plus a no-revert step.

Edits Strapi source? No. Runs Playwright? Yes (the generation journey).
</objective>
