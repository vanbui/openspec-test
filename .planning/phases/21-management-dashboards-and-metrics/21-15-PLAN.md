- **Summary.** `computeDashboardSummary(strapi, today, { viewerDocumentId, runRead })` adds `queueAgeing` (from `createCycleTimesRepository(strapi).queueAgeing`), `reviewsDue` (four register totals through `listRiskRegister`'s count for `{ stage: "released", state: "open", treatmentAction: "Accept", decisionReview }` with `due-soon`, `overdue`, `not-confirmed`, `reviewer-missing`) and, when `runRead`, `failedAiRuns` from `createAiAssistanceRepository(strapi).failedRunCount({ today })`; each part fails alone (07 D-34: a failed part is null with the rest served).
- **Controller.** `summary(ctx)` passes `viewerDocumentId: ctx.state.idamboxUser?.documentId` and `runRead: ctx.state.csrmAuthorization?.analystInsightRunRead === true`.
- **Spec.** `DashboardSummary` gains `queueAgeing: DashboardQueueAgeing | null` (`{ recordedFrom, predatingOpen, team: AgeingTable, yours: AgeingTable }`), `reviewsDue: DashboardReviewsDue | null`, and optional `failedAiRuns: { count, windowStart }` (absent without the run read).
- **Web.** `analyst-dashboard-schema.ts` parses the three (closed; `failedAiRuns` optional); presentation: the Failed row (href `/app/reports/ai-assistance/records`, name `Failed in the last 7 days: {n} AI {run|runs}`), the reviews rows (hrefs `/app/risks?stage=released&state=open&treatmentAction=Accept&decisionReview={state}`, names `{state}: {n} {review|reviews}`), the ageing links; `analyst-dashboard.tsx` renders the Failed row in `Review queue`, the `Queue ageing` unit (`Timer`; description `Open requests by stage and working days in it.
