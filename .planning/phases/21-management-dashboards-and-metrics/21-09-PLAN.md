## Phase Goal

**As a** risk manager or leader, **I want** trends, ageing, cycle times and a heat map, **so that** I can see whether risk and the assessment process are improving.

This plan's slice: the one drill-down read behind every figure no canonical list can reproduce. A Security Analyst can read the episodes behind a stage's median, slowest first, and the rounds behind a round measure, with totals equal to the figures; nobody else can.

<objective>
Serve `GET /api/v1/reports/{reportKey}/records` (D-03 item 2; 21-RESEARCH R10) with its closed parser (D-03 item 7), one `{ figure, rows }` function per kind (D-26), the cycle-times kinds `stage-episodes` and `round-measure` (D-10, D-12), and its whole chain: operation, route, controller, Function in both catalogues, human-only and service-identity refusal sets, the specification, the served inventory, the matrix row for all seven callers, and the web's typed layer (D-02, D-25). Make the insight policy compute its required reads per operation and key, adding Phase 12's run read for `ai-assistance` and refusing a missing read with `INSIGHT_SCOPE_MISSING` (D-02).

Purpose: SC3's "link to the slowest items" and D-26's equal totals for figures no list can reproduce; 21-11 and 21-14 add their kinds to this route.
Output: the published route with its grants and refusals proven, and the typed layer the drill-down page (21-10) reads.

Edits Strapi source? Yes (dev servers stopped). Changes the specification? Yes. Runs Playwright? No.
</objective>

- **Operation and route.** `CSRM_ANALYST_INSIGHT_OPERATIONS.listReportRecords = "GET:/api/v1/reports/{reportKey}/records"`; route `GET /v1/reports/:reportKey/records` → `api::csrm-analyst-insight.reports.records` with `insightPolicies(...listReportRecords)`; it joins `HUMAN_ANALYST_ONLY_OPERATIONS` through the spread and `SERVICE_IDENTITY_REFUSED_OPERATIONS` explicitly.
- **Parser (`report-query.ts`).** `RECORDS_REPORT_KEYS` = the report keys with a drill-down (`cycle-times` now; 21-11 and 21-14 append theirs); `parseReportRecordsRequest(reportKey, query)`: not a report key or not in `RECORDS_REPORT_KEYS` → `ReportNotFoundError`; each parameter exact and single-valued per 21-01's "Drill-downs"; for `cycle-times` exactly one of `stage` or `measure`, `roundOutcome` only with `measure=acceptance-rounds`; `page` an integer 1 to 1,000,000; `pageSize` in `REPORT_RECORDS_PAGE_SIZES` (default 25); anything else → `ReportRecordsQueryError` (400, reason `REPORT_RECORDS_QUERY_INVALID`).
- **Service (`report-records.ts`).** `readReportRecords(strapi, request, today)` dispatches by key to the repository's records function, then slices `rows` by page in code (the sample is already bounded) and returns `{ kind, figure, rows, pagination: { page, pageSize, pageCount, total: figure }, scope: { asAt: today, period, filters } }`.
- **Controller.** `records(ctx)`: `assertAnalystInsightScope(ctx.state)` first; parse; read once with the clock; `handleError` maps `ReportRecordsQueryError` to 400 with `details.reason`.
- **Policy.** `analystInsightRequiredReads(operation, reportKey)` returns `ANALYST_INSIGHT_UNDERLYING_READS` plus `CSRM_AI_RUN_OPERATIONS.getRun` when `reportKey === "ai-assistance"` and the operation is `getReport`, `listReportRecords` or `exportReport`; the insight branch reads `policyContext.params.reportKey`; a missing read denies with the policy's reason-carrying denial, reason `INSIGHT_SCOPE_MISSING`; the granted state gains `analystInsightRunRead: boolean` (whether the viewer holds the run read), which 21-15's dashboard reads. Nothing branches on the auth mode.
- **Catalogue.** Function `function.reports.records_api` (`Report Records API`, description `Human analyst-only drill-down of a report figure. This API-only Function intentionally has no menuPath.`, `roleIds: ["role.security_analyst"]`), FunctionApi `function.reports.records_api.api.01` `List Report Records` with the URL above and `sourceEntities` `CsrmAssessmentRequest`, `CsrmAssessment`, `CsrmRisk`; a design note records it. Docs copy edited, bootstrap copy copied over it.
- **Spec.** Path `/v1/reports/{reportKey}/records` (`get`, operationId `analyst-insights/list-report-records`), the closed query parameters, 200 `ReportRecordsResponse` (`data` `oneOf` `StageEpisodeRecords`, `RoundMeasureRecords` with discriminator `kind`; `meta { pagination, scope }`), 400 with `REPORT_RECORDS_QUERY_INVALID`, 403 with `INSIGHT_SCOPE_MISSING`, 404. `StageEpisodeRecord` = `{ requestDocumentId, requestNumber, title, assessmentDocumentId, assessmentNumber, round { kind, number } | null, enteredAt, leftAt, durationDays }`; `RoundMeasureRecord` = `{ assessmentDocumentId, assessmentNumber, title, round { kind, number } | null, openedAt, closedAt, value, unit }`.
- **Web typed layer.** `report-schema.ts`: `reportRecordsResponseSchema` (closed, discriminated on `kind`), `reportRecordsRequestSchema`; `report-service.ts`: `getReportRecords(key, query)` through the typed client, registered in `responseParserModule` with label `getReportRecords`, component `ReportRecordsResponse`.
