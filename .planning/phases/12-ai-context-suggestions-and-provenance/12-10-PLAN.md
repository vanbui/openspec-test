## Phase Goal

**As a** Security Analyst, **I want to** have the AI work from everything the Requestor gave and show where each proposal came from, **so that** I can trust, check and correct its output quickly.

This plan's slice: the analyst can read what any AI run used, and only a person, never the automation agent, can start AI generation or reach the request writes it no longer needs.

<objective>
Serve the run read (D-25) as a human-analyst-only operation with its web service and Server Action; move draft generation and its job read and retry into human-analyst-only Functions (D-32); withdraw the analyst service agent's three request grants (D-33, R-08-42); update the matrix, the catalogue test, the served inventory and the residual register.

Purpose: INT-05 criterion 2 ("the analyst can see the context a run used") and G-3's accountable human initiator for every run.
Output: one new operation end to end, three moved FunctionApis, three withdrawals, the register closures.

Edits Strapi source? Yes. Changes the specification? Yes. Runs Playwright? No. Regenerates `served-operations.json`? Yes.
</objective>
