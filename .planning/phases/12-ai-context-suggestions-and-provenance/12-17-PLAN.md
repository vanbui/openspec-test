## Phase Goal

**As a** Security Analyst, **I want to** have the AI work from everything the Requestor gave and show where each proposal came from, **so that** I can trust, check and correct its output quickly.

This plan's slice: every AI statement shows where it came from and opens that answer or field in place, claims the AI could not support are flagged, and suggested controls become planned controls in one action.

<objective>
Build the citations and their source popover (X-12, D-14), the uncited claims region, and the suggested controls list with add, dismiss, restore and Undo (D-12, D-24, UI-D11, UI-D12), and place them in each risk card and the assessment details of the editor.

Purpose: ROADMAP criteria 2 and 3 in the UI; INT-06 criterion 2, ASSESS-08 criterion 2; UAT-031 and UAT-042.
Output: four ai-assistance components, the source Server Action, the hook's suggestion paths, and the editor integration.

Edits Strapi source? No. Changes the specification? No (the source popover uses existing reads, D-03). Runs Playwright? Yes (regressions).
</objective>

## Recorded planning decisions

- **Citation labels** come from the served `AiSourceCitation` (12-09): `Answer: {label}`, `Request: {label}`, `System: {label}`, `Asset: {label} · {classification or Not classified}`; the full visible text is the accessible name; answer and request citations carry `aria-haspopup="dialog"` and `aria-expanded`.
- **Source read.** `readAiSourceAction({ requestId, sourceKey })` (`'use server'`, strict input): for `request.{field}` it calls the existing analyst request read and returns `{ kind: "request", label, value, requestNumber, href }`; for `answer.{questionKey}` it reads the request's questionnaire with the existing analyst questions read and returns `{ kind: "answer", questionText, section, helpText, answer (rendered with choice labels or Not answered), href }`; a missing source returns `{ kind: "missing" }`; a 403 returns the permission failure. The popover is loaded with `next/dynamic` from `AiCitations`.
- **Suggestions placement.** `AiControlSuggestions` renders after the risk's mitigation controls and before `Add mitigation control`, `data-print="hidden"`, unreleased only.
- **Toasts.** Add: `{control label} added as a planned control on {risk number}.` with Undo → `Planned control removed. The suggestion is back.`; Dismiss: `Suggestion dismissed: {control label}.` with Undo → `Suggestion restored.`; Restore: `Suggestion restored: {control label}.` (no Undo); failures: `Control not added`, `Suggestion not dismissed`, `Suggestion not restored`, `Couldn’t undo`, with family J copy (UI-SPEC §6.1).
