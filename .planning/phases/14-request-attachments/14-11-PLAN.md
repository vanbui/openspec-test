## Recorded planning decisions

- **Counts** (`attachmentAnalystCounts({ strapi, requestId })` → `{ count, included }`): `count` is files not removed; `included` is files with `aiTextIncluded`, `scanStatus: "clean"` and `removedAt` null. The analyst reads' request summary gains `files: { count, included }`.
- **Signal** (`changedAttachmentInputs({ strapi, requestId, baseline })` → `[{ documentId, fileName, change }]`): `baseline` is `{ kind: "run", includedIds } | { kind: "generated", generatedAt } | null` from the same latest completed context-wide run Phase 12 resolves for `generation`; with a run, `included` for current included ids not in `includedIds`, and for each id in `includedIds` not currently included `removed` when the file is removed, else `excluded`; with only `generatedAt`, `included` for files whose `aiTextFacts.extractedAt` is later; with `null`, none. Ordered by `uploadedAt`. `generation.aiInputsChanged` gains `files` and its `count` adds them; it stays `null` when Phase 13's rule gives no baseline.
- **Spec**: the analyst questionnaire and assessment detail components gain `assessmentRequest.files` (`{ count, included }`, closed) and `generation.aiInputsChanged.files` (`[{ documentId, fileName, change: "included" | "excluded" | "removed" }]`, closed); the Requestor shapes are unchanged.
- **Line** (`assessment-request-link.tsx`, server component): after Phase 13's notes line, a third line in `--text-caption` / `--color-text-secondary`: a figure link (X-10) `{n} {file|files}` → `/app/review/requests/{id}#files`, then ` · {k} included in the AI inputs` when `k > 0`; with `n = 0`, `No files` (plain text).
- **Signal items** (in the header's changed-inputs list): one item per file after the note items, a record link `{name}` → `/app/review/requests/{id}#file-{fileId}` and the caption `Included since`, `Excluded since` or `Removed since` in `--text-caption`; the heading and closing caption are Phase 13's.
